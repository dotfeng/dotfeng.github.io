使用说明

这是什么

这里收集各科竞赛的试题文档，按多级分类整理。每份文档都可以：

  • 在线阅读试题 —— 打开页面即显示完整试卷；
  • 展开答案解析 —— 点击页面下方的「查看答案解析与下载」，展开后可见答案速查表与逐题解析（顶部还有「跳到答案解析」直达按钮）；
  • 下载原文件 —— 展开区底部提供 Word 原文件下载，A4 版式，可直接打印；
  • 答题模式 —— 文字版试卷（天文 52 套 + 数学 AMC 系列 195 套）的详情页顶部有「开始答题 →」，点进去可直接作答并自动判分（详见下方）。

答题模式

文字版试卷（天文卷 52 套 + AMC8 / AMC10 / AMC12 的 P 版中英双语 195 套，共 247 套、7780 题）在详情页顶部有一个绿色的「开始答题 →」按钮，点进去是独立于展示页的答题页面：

  • 题型：按题目自身规则渲染为单选（radio）、多选（checkbox）或填空（文本框）；天文卷的判断题统一渲染为「正确 / 错误」两个单选项。
  • 计时：点击「开始答题」后，页面右上角醒目显示答题耗时，滚动时一直停在顶部。
  • 提交：页面底部「提交答卷」按钮。按钮上方实时显示还剩几题未答；未全部答完也可以提交，点击时会弹出「还有 N 题未作答，未作答的题目将按答错计算」的确认框，确认后即判分，未作答的题按答错计；提交后不可修改。
  • 判分：按该套试卷的答案逐题判定，答错的题目整块描红（含解析区），并在每题选项下方展开正确答案与解析；填空题只给参考答案，不参与判分。原卷标注「作废 / 不计成绩」或缺答案的题目标为「不计分」，不影响得分。
  • 一次性：本模式只做即时判题，不记录作答、不统计历史、不生成错题集，刷新或关闭页面即清空，答题前页面会先给出该提示。
  • 原版图片卷（AMC8 的 PDF 原卷）不提供该按钮；原有「仅题目展示」的页面完全保留，两种模式可随时互相跳转。

分类结构

分类采用多级方式，最多支持四层：

  • 天文 —— CNAO（预赛 / 决赛 / 小学组）、省赛（北京 / 广东 / 浙江 / 江苏 / 山东 / 中国台湾）、练习（小学组练习 / 题库合集）
  • 数学 —— AMC8、AMC8/AMC10/AMC12(P版)（P 版中英双语，分别 41 / 52 / 102 套）、国奥、省赛（山东 / 北京 / 江苏 / 广东）

后续还会陆续增加 物理、化学、信息学 等其他学科，同样按「学科 → 赛事 → 地区 → 组别」的方式继续细分。

怎么找题

  • 顶部导航：鼠标移到「天文」「数学」上会展开下一级，划到带箭头的条目上继续展开下一级；手机端点开右上角「分类」，逐级点击展开。
  • 分类页筛选：进入任一分类后，页面顶部会显示每一级的筛选条，点一下就按该级过滤，上一级、下一级随时可切换。
  • 列表：按年份倒序排列，一页 20 套，超过时底部显示分页条，可翻页或直接跳转到指定页。

白名单竞赛

「白名单」指教育部公布的面向中小学生的全国性竞赛活动名单：只有列入名单的竞赛才可以面向中小学生举办，名单之外的均属违规赛事。本站把 2025—2028 学年的名单整理成了独立页面：

  • 白名单竞赛 —— 共 47 项，分自然科学素养类（22 项）、人文综合素养类（12 项）、艺术体育类（13 项）三大类；
  • 每项列出竞赛名称、主办单位、面向学段；页面顶部可按 小学 / 初中 / 普通高中 / 中职 筛选，便于判断某项赛事是否面向孩子当前学段；
  • 页面顶部附有教育部原通知（教育部办公厅关于公布 2025—2028 学年面向中小学生的全国性竞赛活动的通知）的链接，可核对原文；
  • 入口在顶部导航「使用说明」左侧的「白名单竞赛」。

关于答案与解析

天文部分的答案与解析已逐题核对，个别题目保留原卷表述；AMC8(P版) 部分的题目、选项、解答均直接取自 P 版中文站，公式与题图一并保存到本站（不引用外链）；如与官方答案不一致，请以官方发布为准。发现错漏欢迎指正。
