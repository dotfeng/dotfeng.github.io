答案速查：

1-5： D B D A A

6-10：B B C C B

11-15：B B C D B

16-20：C B A D B

21-25：D A A A B

26-30：D A B A C

31-35： B C D C C

逐题解析：

1. D 预赛当天为2012年3月10日（农历二月十八）：望发生在3月8日，考试时月龄约17天，是满月后两天的亏凸月，即“刚过满月”。故选D。

2. 【B】 2012年金星凌日发生于6月6日。

3. 【D】 北极星视星等约2.0等，在冬季夜空中肉眼可见的较暗恒星中，北极星是选项中最暗的。

4. 【A】 肉眼可见约10颗恒星对应极限星等约3等。

5. 【A】 2011AG5是一颗被认为在2040年有微小概率撞击地球的小行星。

6. 【B】 冲日是指外行星与太阳分居地球两侧，木星在2012年初处于冲日附近。

7. 【B】 冬季大三角由天狼星、北河三和参宿四组成，北河二不属于冬季大三角。

8. 【C】 2012年2-3月夜空中最亮的两颗行星是金星和木星，它们相距最近的日期是2月26日。

9. 【C】 2012年有5月20日的日环食、11月13日的日全食，还有6月4日的月偏食和11月28日的半影月食，但没有月全食，所以“肯定不会发生”的是月全食。

10. 【B】 2012年国际天文学奥林匹克竞赛(IAO)在韩国举办。

11. 【B】 宝瓶座η流星雨在2012年观测条件不太理想。

12. 【B】 猎户座（赤经约5h30m）与狮子座（赤经约10h30m）在天球上相隔约70°，是四个选项里最远的一对；金牛、双子都与猎户座相邻，天琴与天鹰只差约34°。

13. 【C】 未来最近的一次日全食是2012年11月13日，全食带经过澳大利亚昆士兰北部（凯恩斯一带），其次是2015年3月的斯瓦尔巴、2016年3月的印尼，2017年8月才轮到美国。

14. 【D】 神舟八号于2011年11月发射并与天宫一号成功对接。

15. 【B】 天宫一号在理想条件下肉眼可见时亮度可达0等左右。

16. 【C】 天文单位(约1.5亿km) < 光年(约9.46万亿km) < 秒差距(约3.26光年)。

17. 【B】 月球自转周期与绕地球公转周期相同（潮汐锁定），因此始终只能看到一面。

18. 【A】 2012年12月21日只是玛雅历法的一个节点，是普通的日子，并非世界末日。

19. 【D】 2011年12月10日月全食期间，红月亮出现在北京时间约22时左右。

20. 【B】 萤火一号是中国2011年发射的火星探测器，好奇号是美国2012年发射的，创新号不是火星探测器名称。

21. 【D】 C/2011W3(Lovejoy)是2011年肉眼可见的大彗星。

22. 【A】 御夫座离银道面最远。

23. 【A】 2099年9月29日太阳在室女座（赤经约12h30m），月食发生在望，月亮与太阳相对，赤经约0h30m，位于双鱼座。

24. 【A】 嫦娥二号于2010年10月发射，不是2011年发射的。

25. 【B】 发现位于类太阳恒星宜居带上的地球大小系外行星是近年事件，不属于2010-2012年范围。

26. 【D】 开普勒望远镜于2009年3月发射，专门用于搜寻系外行星。

27. 【A】 “全球天文月”（Global Astronomy Month，GAM）由“无国界天文学家”组织发起，固定在每年4月举行。

28. 【B】 M33（三角座星系）是梅西叶天体中距离我们最远的。

29. 【A】 三角视差法是测定近距恒星距离的基本方法。

30. 【C】 2009年诺贝尔物理学奖颁发给了高锟（光纤通信），不属于天文课题。

31. B 北京师范大学天文系从2012年起在全国高校中率先把天文学专业本科招生全部纳入自主选拔录取，不需通过普通高考统招该专业。故选B。

32. 【C】 2011AG5小行星大小约150米左右。

33. D 《天文爱好者》杂志社在北京，预赛当天为2012年3月10日（农历二月十八）：望在3月8日，满月时月亮傍晚升起，此后月出每天推迟约50分钟，3月10日月出约在当晚20点半到21点，与21点最接近。故选D。

34. 【C】 星空摄影必须把镜头手动对焦到无穷远——自动对焦面对点状星光是完全失效的，焦点稍偏星点就会变成模糊的光斑且无法后期补救；三脚架、快门线也很重要，但“能不能对上焦”才是决定星点清晰与否的关键功能。

35. 【C】 截止到2012年2月29日，发现的可能在未来100年撞击地球的小行星数目约400颗。
