2024-2025学年CNAO全国中学生天文知识竞赛预赛A卷

（试题与答案分离版）

【注意事项】请务必仔细阅读！

1.每位考生会拿到一张预赛试卷和一张答题卡。试卷和答题卡都需要填写，且填写的内容必须完全一致。试卷上所有书写用钢笔或签字笔，答题卡上所有书写和填涂用2B铅笔。

2.低年组考生（指2010年1月1日及以后出生，并且没有参加过各项国际天文奥赛的考生）只答本卷的01-30题，高年组考生只答06-35题。

3.本卷为闭卷考试，请答卷人按照自己的真实水平独立完成答卷。按要求在答题卡上填写“姓名”、填涂“试卷类型”（见本注意事项之前的表格第二列）、“准考证号”（在空格处写数字，并填涂每个数字下面对应的部分）、组别（“高”或“低”）以及题目的答案。未按要求填涂的无有效成绩。考试开始30分钟之后才可交卷，并在不影响其他考生答题的情况下安静离开考场。在监考老师宣布考试结束时，该考场所有考生应停止答卷，将试卷和答题卡放在桌上，保持安静离开考场。

4.每题选择一个最接近正确的选项。将对应的字母（A,B,C,D之一）填在试卷上并填涂在答题卡该题号下方的对应处。不会做的题目不选。已填涂的答案如需改正，请用橡皮将原答案尽量擦除干净。每道题答对得4分，答错或多选得-4分，不选得0分。满分120分。草稿只可写在试卷“草稿区”处。

5.本试题、答案及决赛名单将在北京天文馆网站、微博、微信公众号，《天文爱好者》杂志公布。决赛将于5月在汕头举行。

逐题答案与解析

1. A 考试日期为2025年3月29日，当日18时58分朔，并发生日偏食；考前月球正位于太阳与地球之间，日月黄经相同，月相为新月。

2. C 蛇夫座的天区被黄道穿过，属于黄道星座，但不是传统的黄道十二宫之一；长蛇座、巨蛇座、水蛇座都不与黄道相交。

3. D 鹿林天文台约北纬23.5°，冷湖约38.6°，兴隆约40.4°，稻城无名山约29°，四者中鹿林纬度最靠南。

4. C 比邻星是半人马座的一颗红矮星，距太阳4.24光年，是离我们最近的恒星，不属于太阳系；冥王星、谷神星、阋神星都是太阳系天体。

5. D 冬至时太阳直射南回归线，此后直射点转为向北移动，即移动方向由向南转为向北；春分只是直射点经过赤道，方向一直是向北。

6. D 仙女星系（M31）在暗夜下约3.4等，肉眼可见；大、小麦哲伦星云在南半球同样肉眼可见，所以三个都能看到，选3个。

7. A 2025年全球只有3月29日和9月21日两次日偏食，没有日全食（下一次日全食在2026年8月12日）；月全食有3月14日、9月7日两次，2月9日还有一次月掩火星。

8. C 北冕座T是典型的再发新星，1866年、1946年两次爆发相隔约80年，因此爆发周期约80年。

9. B 老人星赤纬-52°42′、水委一-40°18′、海石一-59°33′、十字架二-63°06′，水委一赤纬最靠北。（官方参考答案误作A，按各星实际赤纬应为B）

10. C 朔、望前后太阳与月球的引潮力叠加形成大潮，潮差最大、退潮最甚，农历十六正逢望后大潮，故选C。（官方特别说明：A初三亦按正确答案计分）

11. C 土星光环每半个公转周期（约15年）侧对地球一次，2025年之后再过约14年即2038—2039年，选项中2039年最接近。

12. B 原卷为四幅手势示意图（本电子版缺图）。伸直手臂时，握拳的宽度约10°（单根手指约1°～2°，张开手掌可达20°以上），故官方答案B应为握拳一类的手势。

13. C 原卷为太阳实拍照片（本电子版缺图）。凌日时金星呈边缘清晰、大小固定的圆形黑点，且在数小时内自东向西横穿日面；太阳黑子形状不规则、外围有半影，并随日面自转缓慢移动，故答案为金星。

14. B 能否点燃氢核聚变取决于核心的温度和密度，本质是质量门槛（约0.08倍太阳质量）。木星质量只有太阳的千分之一，核心温度远达不到点火条件，与体积大小、含氢比例无关。

15. A 全球收集的陨石中普通球粒陨石约占80%～90%，是数量最多的一类；铁陨石、无球粒陨石、中铁陨石都只占很小比例。

16. C 天问二号的第二个目标是311P/PANSTARRS，它运行在小行星主带内，却具有彗发和彗尾，被归为主带彗星，故选彗星。

17. B 金等重元素主要靠中子星并合过程中的快中子俘获（r过程）合成，2017年GW170817及其光学对应体观测证实了这一点；超新星爆发只能贡献一小部分。

18. C 水星是类地行星中除地球外唯一具有全球性内禀磁场的行星（虽很弱）；火星只有岩石剩磁、没有全球磁场，金星没有磁场，土星属于巨行星而非类地行星。

19. A 由L=4πR²σT⁴，L_A/L_B=(2)²×(1/2)⁴=4×1/16=1/4，即恒星A的光度是B的1/4。

20. D 5月1日午夜，该台址的地方恒星时约13～14时：大角星（RA 14h15m、Dec+19°09′）几乎正位于上中天，地平高度约80°，最适观测；土星（RA 23h54m）已西沉，昴星团尚未升起，南门二在该纬度最高仅约0.2°，故选D。

21. C 宇宙线中约90%是质子（氢核），其次约9%是氦核，电子和中微子只占极小部分。

22. A 芒种日太阳赤纬约+22.6°，北京白昼最长，日出约04:45（寅时）、日落约19:40（戌时）；晷针影子在晷面上随时角均匀转动，由寅时顺时针扫到戌时。

23. A 距离8.6光年≈2.64pc，m-M=5lg2.64-5≈-2.9，系统总绝对星等约1.4等；B的光度只有系统的万分之一，比系统暗10个星等，故M_B≈1.4+10≈11.4，最接近11.5等。

24. D 2024年7月我国科研人员在嫦娥五号月壤中首次发现的是“分子水”（含水矿物中的水分子），并非液态水，故D表述错误；天关卫星、嫦娥六号采样量、LHAASO伽马射线泡三项均正确。

25. A 观测波长=(1+z)×静止波长=4×121.6nm=486.4nm，正落在g波段（400～550nm）内；MgII观测波长为1119nm、[OII]为1491nm、Hβ为1947nm，均已移出该波段。

26. A 日食时月球位于太阳与地球之间，日月黄经相同，即朔（农历初一）；望日地影投向月球，发生的是月食。

27. C 3月5日为农历二月初六，月球在太阳以东约70°。上弦月于日落时上中天，而初六比上弦早一天多，上中天约提前1小时，故北京约17时月球上中天，与C相符。

28. D 简仪、浑仪都是赤道式装置，安装时须按当地纬度调整极轴倾角；地平式日晷的时刻线随纬度改变，也受纬度影响；象限仪以当地铅垂线（地平）为基准测量天体高度，与地理纬度无关。

29. B 低海拔台址的大气相干长度（Fried参数r₀）约10～15cm，对应视宁度约1″；口径超过r₀（约150mm）之后，单张长曝光图像的角分辨率不再随口径提高。

30. D 朔望月平均29.53天，朔到望平均14.77天；朔在初一这一天内的平均位置是0.5天，故平均满月时刻为初一0时之后第15.27天，即农历十六6时前后。

31. A 夫琅和费线用字母命名（大写A、B、C…K，小写a、b…h，如H为396.8nm的钙线、h为410.1nm的氢线、D₁为钠线）；He是元素符号“氦”，不是谱线名称。

32. B LHAASO通过地面探测宇宙线簇射产生的切伦科夫光，可测量10¹⁵eV（PeV）量级的光子；FAST工作在射电波段，HXMT针对硬X射线，DAMPE针对GeV—TeV的电子和伽马。

33. D 岁差是地球自转轴绕黄极的缓慢进动，等价于春分点沿黄道西退；赤经、赤纬、黄经都随之改变，而黄纬基本不变，变化最小。

34. D 辐射点地平高度为h时，可见流星数N∝sin h（ZHR换算关系），随高度增加按正弦规律增长，h=90°时最大。

35. B 周年光行差位移=κ·sinθ，θ为恒星与地球运动“奔赴点”的角距。3月29日太阳黄经约8°，奔赴点在黄经98°附近（RA约6h30m、Dec+23°）；角宿一距奔赴点约106°，sinθ≈0.96，为四者中最大。
