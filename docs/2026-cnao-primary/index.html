四、简答题答案（每题5分，共25分）

1. 请简要解释为什么我们只能看到月球的同一面（即"月球同步自转"）？

月球的自转周期和公转周期相同，都是约27.3天。这种现象称为"同步自转"或"潮汐锁定"。由于月球自转和公转周期一致，月球始终以同一面朝向地球，因此我们在地球上只能看到月球的正面。

2. 什么是"金星凌日"现象？它发生的原理是什么？

"金星凌日"是指从地球上看，金星从太阳盘面经过的天文现象。其原理是：当金星运行到地球和太阳之间，且三者恰好排成一条直线时，金星会像一个小黑点一样在太阳表面移动。金星凌日非常罕见，成对出现，间隔长达百年以上。

3. 列举三种人类探测太阳系天体的方式，并各举一个例子。

（1）飞掠探测：如"旅行者1号"飞掠木星和土星；（2）环绕探测：如"嫦娥一号"环绕月球；（3）着陆探测：如"玉兔号"月球车在月球表面巡视探测。

4. 简述四季星空变化的主要原因。

四季星空变化的主要原因是地球的公转。地球在绕太阳公转的过程中，不同季节夜晚面向的星空方向不同，因此我们在不同季节看到的星座和恒星也不同。例如夏季可见天蝎座和牛郎星，冬季可见猎户座和天狼星。

5. 什么是"暗物质"和"暗能量"？它们在宇宙中扮演什么角色？

暗物质是一种不发光、不与电磁波相互作用的物质，但通过引力效应可以探测到其存在，它约占宇宙总质能的27%，是维持星系旋转速度的关键。暗能量是一种推动宇宙加速膨胀的神秘能量，约占宇宙总质能的68%。两者合计占宇宙总质能的95%以上，是宇宙的主要组成成分。

（2）这个距离在天文学上被定义为1个天文单位（AU）。

逐题详细解析

一、单项选择题详细解析

1、B 解析：对于北半球的观测者，北极星的地平高度角近似等于观测者所在地的纬度。北京纬度约为北纬40度，因此北极星的高度角也约为40度。

2、A 解析：金星和水星属于地内行星，它们与太阳的角距离始终不会太大，总是出现在黎明前的东方或黄昏后的西方，不可能在深夜出现在天顶附近。

3、A 解析：春分日，太阳直射赤道。对于赤道上的观测者，在春分日正午，太阳正好位于天顶。

4、C 解析：开普勒第三定律：T平方=a立方。代入a=4 AU，得T平方=64，所以T=8年。

5、B 解析：望远镜放大倍率M = 物镜焦距 / 目镜焦距 = 1200mm / 10mm = 120倍。

6、B 解析：M31是著名的仙女座大星系，位于仙女座，是一个巨大的旋涡星系，也是肉眼可见的最遥远天体之一。

7、B 解析：月全食时，月球进入地球的本影。太阳光中波长较短的蓝紫光在地球大气层中被强烈散射掉，而波长较长的红光能穿透大气层并发生折射，照射到月球表面再反射回地球，使月球呈现暗红色。

8、A 解析：北斗七星在中国古代天文体系中常被称为"北斗"或"斗"，其形状像一把勺子（斗），用于指示方向和季节。

9、B 解析：初亏发生在日落之前（17:22早于日落17:39），太阳在带食状态下落下，说明是日食；日落前太阳只被遮住一小部分，看不到食甚，因此最可能是日偏食。月食的初亏发生在满月的夜间，与日落前初亏的情形不符。

10、B 解析：太阳半径约69.6万公里，日地平均距离约1.5亿公里，按比例缩小太阳至1cm，日地距离约为2.2m（约215厘米）。

11、C 解析：英仙座流星雨极大期在8月中旬，2026年8月12日前后恰逢新月，整夜没有月光干扰，后半夜辐射点升高后观测条件最佳。

12、B 解析：2026年11月26日天王星冲日，此时它位于金牛座（在昴星团与毕星团之间），整夜可见，是观测天王星的好时机。

13、A 解析："中国复眼"二期建成后将成为千米级虚拟射电望远镜，大幅提升我国在射电天文领域的观测能力。

14、B 解析：JWST在该超冷亚恒星的光谱中探测到最强的水（H2O）吸收带，为研究亚恒星大气的化学成分提供了重要信息。

15、B 解析：根据开普勒第三定律T平方=a立方，T=8年，T平方=64，所以a=4 AU。

16、A 解析：当相位角接近0度时，ISS的太阳能板正对太阳和观测者，反射面积最大，因此亮度达到最高。

18、B 解析："太空中性原子成像"试验的首要科学目标是研究太阳风与地球磁层之间的相互作用过程。

19、D 解析：帕克探测器在近日点时速度最快，距日心约8.8倍太阳半径时，轨道速度接近200 km/s。
