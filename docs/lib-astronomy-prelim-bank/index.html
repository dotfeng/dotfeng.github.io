4. C 月球是地球唯一的天然卫星，围绕地球公转。

196. C 1922年10月30日，中国天文学会在北京古观象台（当时为中央观象台）成立；1992年设立“中国天文日”以纪念此事，并作为开展天文科普的日子，故为10月30日。注意与4月24日“中国航天日”（纪念1970年东方红一号发射成功）区分。

197. A 已知最遥远星系的红移约14，距离我们约135亿光年（光行距），选项中130亿光年最接近。

198. A 北斗系统除提供定位、导航、授时服务外，还具备短报文通信功能。

199. B 隼鸟2号从小行星“龙宫”带回的样品中发现了含水矿物，说明这类碳质小行星可能在早期为地球送来水。

200. A 脉冲星是快速自转的中子星，沿磁极方向周期性地发射电磁脉冲。
