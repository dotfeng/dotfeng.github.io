逐题答案与解析

1. D 2026年2月17日的日环食，环食带主要扫过南极洲，最大食分出现在南极附近，因此最佳观测地在南极；我国境内看不到这次食。故选D。

2. D 阿尔忒弥斯II（Artemis II）计划于2026年实施，4名航天员乘猎户座飞船绕月飞行后返回，是1972年阿波罗17号之后人类首次载人离开近地轨道。故选D。

3. A 1969年7月20日，阿姆斯特朗乘阿波罗11号登月，成为第一个踏上月面的人。加加林是第一个进入太空的人，杨利伟和翟志刚是我国的航天员。故选A。

4. B 1961年4月12日，苏联航天员加加林乘东方1号飞船绕地球飞行一圈，成为第一个进入太空的人类。故选B。

5. D 地球公转使太阳直射点在南北回归线之间往返移动，产生四季变化和昼夜长短的变化；昼夜交替源于自转，月相源于月球的公转，潮汐主要由月球和太阳的引潮力造成。故选D。

6. A 天狼星（大犬座α）视星等约−1.46等，是全天最亮的恒星，也是冬季夜空中最亮的星；参宿四、南河三、毕宿五都比它暗。故选A。

7. C 农历八月十五，日、地、月大致成一线、月球位于太阳的对侧，被照亮的半球正对地球，因此是满月。故选C。

8. C 金星黎明出现在东方称“启明”，黄昏出现在西方称“长庚”；岁星是木星、荧惑是火星、镇星（填星）是土星。故选C。

9. C 太阳靠核心的氢核聚变发光发热，是一颗G2V型主序星，属恒星。故选C。

10. A 仙后座的五颗亮星排成醒目的“W”（或“M”）形，横跨北天银河，是寻找北极星的重要路标。故选A。

11. C 2025年7月1日，ATLAS巡天发现第三个来自太阳系外的天体，编号3I/ATLAS；此前两颗分别是1I/’Oumuamua（2017年）和2I/Borisov（2019年）。故选C。

12. B 土星拥有太阳系最壮观的光环，主要由冰粒和岩石碎块组成；木星、天王星、海王星也有环，但非常暗弱。故选B。

13. B 火星表面覆盖富含氧化铁的沙尘，反射红光，被称为“红色星球”。故选B。

14. A 截至2025年，国际天文学联合会确认的土星卫星已达270余颗，超过木星，是太阳系卫星最多的行星。故选A。

15. D 地球自转使各地轮流朝向太阳，形成昼夜交替；四季变化源于公转，月相源于月球公转，日食是月球遮挡太阳。故选D。

50. B 流星是行星际的小石块、尘埃闯入地球大气层，与大气摩擦燃烧发光的现象；彗星本体并不会进入大气。故选B。

51. B 夏季大三角由天琴座织女星、天鹰座牛郎星和天鹅座天津四组成。故选B。

52. B 小熊座紧邻北天极，北极星（勾陈一）就在其中；仙后座虽然也靠近北天极，但本题最贴切的是小熊座。故选B。

53. B 北极星即小熊座α（勾陈一），目前距北天极不到1°。故选B。

54. A 2025年11月，高海拔宇宙线观测站“拉索”（LHAASO）发表成果，破解了宇宙线能谱“膝”区（约3拍电子伏处陡然变陡）的形成机制。故选A。

55. A 折射式望远镜用透镜作物镜成像；反射式用凹面镜，射电望远镜用天线接收无线电波。故选A。

56. C 地球公转一周约365.26天，即一年。故选C。

57. D 1609年伽利略把望远镜指向天空，最先观测的是月球并画出月面图，随后才发现木星的四颗卫星、金星的位相和太阳黑子。故选D。

58. C 农历初一，月球位于太阳与地球之间，被照亮的一面背对地球，我们看不到月亮，称为新月（朔）。故选C。

59. B 主带小行星集中在火星与木星轨道之间。故选B。

60. A 木星古称岁星（约12年绕天一周，古人用以纪年）；荧惑是火星，太白是金星，镇星是土星。故选A。
