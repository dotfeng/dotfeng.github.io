第9题 答案：B 解析：俄罗斯2022年公布的登月计划是“月球-25”（Luna 25）着陆器，而不是“月球-27”——月球-27是更晚的后续任务，编号对不上，故B最不准确。（月球-25实际推迟到2023年8月发射。）

第10题 答案：A 解析：2022年4月16日从天宫返回的是神舟十三号乘组：翟志刚、王亚平、叶光富（题干按原计划写作3月）。聂海胜是2021年9月17日返回的神舟十二号乘组（聂海胜、刘伯明、汤洪波），因此“不包括”的是聂海胜。

第11题 答案：C 解析：太阳的光谱型为G型。

第12题 答案：D 解析：A是球状星团、B是星云、C是疏散星团、D是星系，图中的天体是M51星系。

第13题 答案：A 解析：视宁度用于度量大气扰动对天体影像的影响。

第14题 答案：B 解析：根据距离模数公式 m-M = 5log(d/10pc)，可得 d ≈ 29.5 pc。

第15题 答案：D 解析：大气消光量近似正比于1/cos z（即 sec z）。

第16题 答案：A 解析：245万光年 ≈ 0.75 Mpc。

第17题 答案：A 解析：用眼罩挡着一只眼是为了在各处走动时保护暗夜视力。

第18题 答案：C 解析：万有引力大小与两物体质量成正比。

第19题 答案：D 解析：右图的装置是VLT（甚大望远镜）。

第20题 答案：B 解析：新月时太阳和月球在同方向，引潮力叠加，潮汐现象最为明显（大潮）。

第21题 答案：B 解析：对应②天文学家编列星表。

第22题 答案：A 解析：对应①阿里斯塔克测量日月大小和距离。

第26题 答案：D 解析：星图中可辨认出北斗和北极星，恒星A在斗口，D是四个选项中唯一一颗属北斗七星的恒星——天璇。

第27题 答案：C 解析：这是一颗亮于1等的恒星，根据周边恒星排列和亮度可判断这是五车二，位于御夫座。

第28题 答案：D 解析：B星是天枢，赤纬+61°45′，它到北极星的距离约90°-61°45′=28°15′。天枢上中天时地平高度为31°35′，得北极星地平高度为31°35′-28°15′=3°20′，北极星的地平高度等于当地纬度。

第29题 答案：A 解析：上中天的天体的赤经等于本地恒星时，天枢赤经为11ⅴ04ᵀ。

第30题 答案：B 解析：小岛本地恒星时11ⅴ04ᵀ，亚历山大恒星时8ⅴ24ᵀ，经度差2ⅴ40ᵀ=40°，亚历山大经度东经30°，小岛经度为东经70°。

第31题 答案：C 解析：地轴进动（岁差）会让天体的赤道坐标出现较明显的变化，300多年的差异不可忽略。

第32题 答案：D 解析：在星下点，观测者与装置的距离为6100-5670=430km，装置的角直径为2×12m/430000m ≈ 5.58×10⁻⁵ rad ≈ 11.5″。

第33题 答案：A 解析：辐射流 = 314W/(4×3.14×(4.3×10⁵m)²) ≈ 1.35×10⁻¹⁰ W/m²。

第34题 答案：C 解析：由普森公式 m = −2.5 lg(F/F₀) = −2.5 lg(1.35×10⁻¹⁰ ÷ 2.52×10⁻⁸) = −2.5 lg(5.36×10⁻³) ≈ 5.68，即约5.7等。

第35题 答案：B 解析：人眼分辨率约1-2′，极限星等约6.5等，可以看见该装置，但看不清其轮廓，是一个点源。

第36题 答案：D 解析：接收功率正比于通光面积，即与口径的平方成正比。题干要求忽略反射衰减和副镜遮挡，故功率比 =(200/7)² ≈ 816，正好是选项D。（若另按约80%的通过效率估算得653，仍以D最接近。）

第37题 答案：C 解析：望远镜不能提高面源的面亮度：口径加大只是收集更多光、把像放大，出瞳一旦超过人眼瞳孔，多出的光就浪费了，面亮度不会“显著提高”，故C不可能。其余三项都成立：A 分辨率与口径成正比，细节更多；B 同一台镜放大率越高，像的立体角越大，面亮度越低；D 焦距变长、焦比变大，面亮度∝(D/f)² 随之下降。

低倍率和高倍率下木星影像的对比。同一台望远镜，放大率提高后像变大、面亮度明显下降。

第38题 答案：C 解析：预报以世界时给出，需换成本地时间。日落前月食已开始，带食月出，可见全食阶段。

第41题 答案：D 解析：月食开始时世界时约9:09，结束时约12:49，撒哈拉沙漠在此期间未经历夜晚。

第42题 答案：B 解析：掩终时月亮圆面已有5%恢复，掩始时月食未生光，掩终时已生光。

第43题 答案：C 解析：本次是月全食，月光大大减弱，掩星观测的成功率明显提高，A的说法可以接受；掩始发生在食既之后、生光之前，位于月球暗面，可以看到，B正确；生光时只有月球东边缘先变亮（掩终时月面仅恢复约5%），而掩终发生在月球西边缘，那里仍是暗面，所以“掩终发生在亮面、难以观测”不符合实际，C最不准确；掩星过程中天王星确实被月球遮挡，D正确。

第44题 答案：A 解析：由 T²∝a³（开普勒第三定律），只要知道各行星的周期比，就能得到轨道半径比，这正是卡西尼时代已知的比例关系。牛顿万有引力定律虽能解释这一规律，但“T与a的比例关系”本身是开普勒第三定律。〔注〕官方答案页作B——该卷选项顺序中B为开普勒第三定律；本卷选项顺序下应选A。

第48题 答案：A 解析：视差角 θ = b/d = 5.8×10³ km/(0.55×1.5×10⁸ km) ≈ 15″，取最接近选项A（14.6″）。
