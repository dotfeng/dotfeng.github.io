2018年3月24日 闭卷

【注意事项】请务必仔细阅读！

1、每位考生会拿到一张预赛试卷和一张答题卡。试卷和答题卡都需要逐题填写，并且填写的内容必须完全一致。试卷和答题卡填写内容不一致的题目每题得 -4分。

2、低年组考生（指2003年1月1日以后出生，并且没有参加过国际天文奥赛IAO和亚太天文奥赛APAO的考生）只答本卷的01-30题，高年组考生只答06-35题。

3、本卷为闭卷考试，请答卷人按照自己的真实水平独立完成答卷，并认真、完整地用签字笔在试卷上填写有关信息、答卷并签字，用2B铅笔在答题卡上按要求签名（应与试卷上的签名一致；签名明显不一致的取消参赛资格），填涂试卷类型（见本注意事项之前的表格第二列）、准考证号（在空格处写数字，并填涂每个数字下面对应的部分）、组别，以及每道题的答案。未按要求填涂的取消考试成绩。考试开始30分钟之后才可交卷，并在不影响其他考生答题的情况下安静离开考场，否则取消考试成绩。在监考老师宣布考试结束时，该考场所有考生应停止答卷，将试卷和答题卡放在桌上，保持安静离开考场。

4、每题选择一个最接近正确的答案。将对应的字母（A，B，C，D之一）填在试卷上并填涂在答题卡该题号下方的对应处。不会做的题目不选。已填涂的答案如需改正，请用橡皮将原答案尽量擦除干净。每道题答对得4分，答错或多选得-4分，不选得0分。满分120分。草稿可写在试卷草稿区处。

5、本试题、答案及决赛名单将在北京天文馆网站公布。

【试题】

1、M51位于（　　）。

（A）小熊座　　（B）大熊座　　（C）天琴座　　（D）猎犬座

2、木星的卫星中体积最大的是（　　）。

（A）木卫一　　（B）木卫二　　（C）木卫三　　（D）木卫四

3、以下恒星无法在今晚观测到的是（　　）。

（A）天狼星　　（B）织女星　　（C）大角星　　（D）北落师门

4、下列星座中不相邻的是（　　）。

（A）英仙座与飞马座　　（B）宝瓶座与南鱼座　　（C）天龙座与武仙座　　（D）室女座与后发座

5、火星在2018年大冲时位于哪个星座天区内？（　　）

（A）摩羯座　　（B）天秤座　　（C）巨蟹座　　（D）狮子座

6、此时，太阳直射地球（　　）。

（A）北回归线附近　　（B）赤道北侧一点　　（C）赤道南侧一点　　（D）南回归线附近

7、此时，月球与太阳的角距约为（　　）。

（A）45°　　（B）90°　　（C）120°　　（D）180°

8、以下梅西叶天体中与银河系最相似的是（　　）。

（A）M31　　（B）M32　　（C）M82　　（D）M87

9、南河三和北河三分别位于天球上那个大圆的两侧？（　　）

（A）黄道　　（B）天赤道　　（C）银道　　（D）其他三个选项都不正确

10、太阳的绝对星等是（　　）。

（A）-26.8　　（B）0.0　　（C）4.8　　（D）8.6

11、瑞典皇家科学院将2017年诺贝尔奖授予美国科学家雷纳·韦斯、巴里·巴里什和吉普·索恩，以表彰他们对探测（　　）做出的贡献。

（A）引力波　　（B）中微子　　（C）暗物质　　（D）暗能量

12、人类最近一次观测到银河系内的超新星爆发是在（　　）年。

（A）1054　　（B）1604　　（C）1987　　（D）2018

13、2017年6月15日，硬X射线调制望远镜（　　）在酒泉卫星发射中心发射升空，弥补了我国空间X射线探测的空白。

（A）悟空　　（B）天眼　　（C）慧眼　　（D）墨子

14、在月球上观测，地球和太阳的视直径比大约是（　　）。

（A）1:1　　（B）3:2　　（C）2:1　　（D）7:2

15、以下流星雨中，2018年极大期间的月相最有利于观测的是（　　）。

（A）宝瓶座η流星雨　　（B）英仙座流星雨　　（C）双子座流星雨　　（D）小熊座流星雨

16、一位天文学家和一位同学相约观测织女星。某天晚上的某个时刻，天文学家在格林尼治天文台观测到了织女星上中天，那么此后多久这位同学将在北京天文馆（116°20′E，39°56′N）观测到织女星上中天？（　　）

（A）7小时44分　　（B）8小时15分　　（C）16小时12分　　（D）16小时15分

17、下次日全食将发生在北京时间（　　）。

（A）2018年8月11日　　（B）2019年7月3日　　（C）2019年12月26日　　（D）2020年6月21日

18、以下关于2018年即将发射的凌星系外行星巡天望远镜（TESS）说法错误的是？（　　）

（A）它将在椭圆轨道上绕地球运行。 （B）它将对开普勒望远镜之前发现的岩态行星进行进一步探测。 （C）它的目标是1到2倍地球大小的系外行星。 （D）除了观测系外行星，它还将被广泛应用于观测其他类型的目标。

19、以下关于月球的事实哪个最有可能是巧合？（　　）

（A）在地球上观测月球和太阳看上去差不多大　　（B）月球总是固定的一面朝向地球　　（C）月球背面的环形山比正面多　　（D）月球公转轨道和地球的公转轨道面夹角很小

20、以下彗星中2018年回归近日点的是（　　）。

（A）1P/Halley　　（B）2P/Encke　　（C）62P/Tsuchinshan　　（D）C/2016 R2

21、首先提出“黑洞蒸发”理论的天文学家是（　　）。

（A）爱因斯坦　　（B）爱丁顿　　（C）钱德拉塞卡　　（D）霍金

22、2017年9月15日，卡西尼号探测器以坠入（　　）大气层的方式结束了它的探测任务。

（A）金星　　（B）木星　　（C）土星　　（D）海王星

23、太阳位于银河系中的哪个组成部分里？（　　）

（A）银心　　（B）核球　　（C）银盘　　（D）银晕

24、最大的折射式望远镜的口径是（　　）。

（A）1.0m　　（B）2.4m　　（C）5.4m　　（D）8.0m

25、在地球上观测，下列哪种情况不可能发生？（　　）

（A）行星中水星距离地球最近　　（B）一年出现3次金星大距　　（C）火星比木星亮　　（D）一年出现4次日食

26、在地球上观测周年日行迹的形状很像（　　）。

（A）0　　（B）1　　（C）8　　（D）S

27、2018年1月31日的月全食发生期间，以下梅西叶天体中与月球角距离最近的是（　　）。

（A）M37　　（B）M44　　（C）M47　　（D）M76

28、2018年1月31日除发生了月全食外，还上演了谷神星冲日天象，下一次谷神星冲日将发生在（　　）。

（A）2018年10月12日　　（B）2019年5月31日　　（C）2020年3月25日　　（D）2020年9月9日

29、目前得到确认的人类最古老的天文观象台是（　　）。

（A）位于中国临汾的陶寺遗址　　（B）位于中国安阳的殷墟遗址　　（C）位于英国威尔特郡的巨石阵　　（D）位于中国北京的古观象台

30、通常认为白矮星的质量上限为1.44个太阳质量，而稳定恒星的质量上限约为（　　）个太阳质量。

（A）8　　（B）50　　（C）150　　（D）500

31、以下天象可能发生在对应农历日期的是（　　）。

（A）月掩毕宿五发生在除夕　　（B）月掩心宿二发生在正月初五　　（C）月掩轩辕十四发生在正月十五　　（D）月掩角宿一发生在二月初二

32、以下天象出现频率最低的是（　　）。

（A）金星上的水星凌日　　（B）地球上的水星凌日　　（C）地球上的金星凌日　　（D）火星上的金星凌日

33、欧洲空间局盖亚（GAIA）卫星测量视星等为15等恒星视差的精度为20微角秒，那么它对于视星等15等恒星理论上的最远探测距离为（　　）。

（A）2000光年　　（B）10000秒差距　　（C）50000秒差距　　（D）200万光年

34、一位同学计划拍摄2018年大冲期间的火星和壮观的银河，以下哪个日期和地点是最佳选择（　　）？

（A）7月26日 澳大利亚　　（B）7月27日 南非　　（C）7月28日 北京　　（D）7月28日 智利

35、1838年，德国天文学家贝塞尔首次利用高自行的（　　）测出了恒星的视差。

（A）天狼星　　（B）比邻星　　（C）巴纳德星　　（D）天鹅座61双星

答案速查表

第1~10题：D C D A A　B B A A C

第11~20题：A B C D B　D B B A D

第21~30题：D C C A B　C B B A C

第31~35题：C C C D D

逐题答案与解析

1、【D】 M51（涡状星系）位于猎犬座。

2、【C】 木卫三（盖尼米德）是木星卫星中体积最大的，也是太阳系中最大的卫星。

3、【D】 北落师门赤纬约-29.6°，在北京（40°N）最高也只有20°左右，3月下旬要到21:50前后才升起、且整夜低悬南方；天狼星此时正从西南方下落，大角星已从东方升起，织女星后半夜高挂，四颗星中北落师门是最难观测到的，故选D。

4、【A】 英仙座与飞马座之间隔着仙女座和三角座，两者天区不相邻；宝瓶—南鱼、天龙—武仙、室女—后发都是相邻的，故选A。

5、【A】 2018年7月27日火星大冲时位于摩羯座天区。

6、【B】 3月24日接近春分（3月21日），太阳直射赤道北侧一点。

7、【B】 2018年3月17日为朔，3月24日正是上弦，日月角距约90°，故选B。

8、【A】 M31是Sb型旋涡星系，有核球、旋臂和盘，与银河系（SBbc）结构最相似；M32是M31的伴生椭圆星系，M82是星暴星系，M87是巨椭圆星系，故选A。

9、【A】 黄道（太阳周年视运动路径）正好从南河三与北河三之间穿过：北河三的黄纬约+6.7°，南河三约-16°，两者分居黄道两侧。天赤道则不然——南河三赤纬+5.2°、北河三+28°，都在天赤道以北，故选A。

10、【C】 太阳的绝对星等约为4.8等。

11、【A】 2017年诺贝尔物理学奖授予引力波探测的贡献者。

12、【B】 人类最近一次观测到银河系内超新星是1604年的开普勒超新星。

13、【C】 2017年6月15日发射的是慧眼（HXMT）硬X射线调制望远镜。

14、【D】 在月球上看地球视直径约1.9°，太阳约0.5°，比值约7:2。

15、【B】 2018年8月11日为朔，英仙座流星雨极大（8月12—13日）恰好赶上无月夜，观测条件极佳；宝瓶座η流星雨极大时（5月6日）月龄已近20天，双子座（12月14日）和小熊座（12月22日）流星雨极大期间都靠近上弦和满月，故选B。

16、【D】 北京在格林尼治以东约116.3°，同一颗恒星上中天的时间比格林尼治早 116.3°/15≈7小时45分。因此在格林尼治看到织女星上中天后，北京那一次上中天已经过去7小时45分了，要再等 24h-7h45m≈16小时15分，故选D。

17、【B】 2018年3月24日之后的下一次日全食是2019年7月2日（世界时），对应北京时间7月3日凌晨，全食带落在南太平洋—智利—阿根廷一带；2019年12月26日那次是日环食（我国可见），不是日全食，故选B。

18、【B】 TESS在一条13.7天的椭圆轨道上绕地球运行，主要目标是在离我们较近的亮星周围寻找1～2倍地球大小的系外行星，并把它们交给后续观测（如JWST）做大气研究；它并不是用来“复检开普勒已发现的岩态行星”——开普勒的目标星大多很远、很暗，TESS并不以它们为主要对象，故B说法错误。

19、【A】 在地球上观测月球和太阳看上去差不多大是巧合——月球虽小但离地球近，太阳虽大但离地球远。

20、【D】 C/2016 R2（PanSTARRS）于2018年5月9日过近日点，是当年最受关注的彗星之一；1P/Halley上次近日点在1986年，2P/Encke的近日点在2017年3月和2020年，62P/Tsuchinshan的周期约6.6年、上一次近日点在2017年前后，故选D。

21、【D】 霍金1974年发表论文，指出考虑量子效应后黑洞会以热辐射的形式缓慢蒸发（霍金辐射），故选D。钱德拉塞卡提出的是白矮星的质量上限，爱因斯坦和爱丁顿都与黑洞蒸发无关。

22、【C】 卡西尼号在2017年9月15日按计划主动坠入土星大气层，结束13年的土星探测，故选C。

23、【C】 太阳位于银河系的银盘上，距银心约2.5万光年、在银道面附近，属于猎户臂（一条较小的旋臂），故选C。银心是中心黑洞所在处，核球是银心周围的椭球状结构，银晕是老恒星和球状星团分布的球状区域。

24、【A】 世界上最大的折射式望远镜口径为1.0米。

25、【B】 金星的大距每约146天和约438天交替出现，因此一个日历年里最多只能有2次大距，不可能出现3次，故B不可能。其余三项都可能：水星在下合、金星在上合时，水星确实是离地球最近的行星；2018年7月火星大冲时亮度约-2.8等，比木星（约-2.4等）更亮；一年中出现4次日食也确有其例（如2011年）。

26、【C】 周年日行迹（analemma）的形状像8。

27、【B】 2018年1月31日月全食时，月球位于巨蟹座，与蜂巢星团M44（巨蟹座）角距只有几度，是四者中最近的；M37在御夫座、M47在大犬座、M76在英仙座，都相距很远，故选B。

28、【B】 谷神星的会合周期约466天，2018年1月31日冲日之后，下一次冲日约在2019年5月底，故选B。

29、【A】 山西襄汾陶寺遗址发现了距今约4100年的古观象台遗迹（由13根夯土柱组成的观测缝），是目前公认的世界最古老天文观象台；殷墟是商代都城遗址，巨石阵约建于公元前3000—前2000年，北京古观象台建于明代，故选A。

30、【C】 稳定恒星的质量上限约150个太阳质量，超过这一数值辐射压会把外层吹散；1.44个太阳质量是白矮星的质量上限（钱德拉塞卡极限），两者不要混淆，故选C。

31、【C】 农历十五是望，月亮与太阳相差180°，因此能与满月相伴的亮星必须位于太阳的对侧。正月十五时太阳在宝瓶—双鱼一带，满月就在狮子—室女一带，而轩辕十四正在狮子座，故月掩轩辕十四可能发生在正月十五。除夕和初二都是朔前后，月亮贴着太阳，不可能去掩毕宿五、角宿一；正月初五是蛾眉月，也不满足条件，故选C。

32、【C】 金星凌日在地球上极为罕见，以成对出现（间隔8年），对之间间隔超过百年。

33、【C】 最远探测距离 d = 1/p = 1/(20×10^-6角秒) = 50000秒差距。

34、【D】 2018年7月27日火星大冲，智利位于南半球，观测条件最佳。

35、【D】 1838年贝塞尔首次利用天鹅座61双星测出恒星视差。
