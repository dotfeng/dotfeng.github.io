用数码单反相机进行星空摄影，对质量好坏影响最大的因素是（　　） A、感光度 B、曝光时间 C、光圈 D、调焦

下列恒星距离黄道最远的是（　　） A、心宿二 B、角宿一 C、大角 D、五车二

牛郎星两边各有一颗小星，排列整齐，这是人们常说的（　　） A、天津四 B、扁担星 C、人马座 D、天蝎座

M1蟹状星云(Crab Nebula)是梅西耶星表中排名第一的天体。它位于哪个星座？（　　） A、巨蟹座 B、金牛座 C、天蝎座 D、猎户座

以下恒星与所在星座写的不对的是（　　） A、天狼星，大犬座 B、南河三，双子座 C、参宿七，猎户座 D、轩辕十四，狮子座

假设天气晴朗，一年中以下日期中最适于进行梅西叶天体马拉松观测的日期是（　　） A、2月7日 B、3月28日 C、7月5日 D、11月17日

查看答案解析与下载

B 金星是离地球最近的行星，2023年3月24日前后可在傍晚西方天空观测到金星与月球靠近。

B 日食发生在朔日，即农历初一，此时月球位于太阳和地球之间。

A 英仙座流星雨活跃期为每年7月下旬至8月下旬，8月13日前后达到极大，是北天三大流星雨之一。

D 天王星距离太阳最远，公转周期约84年，在四个选项中最长。

C M57是环状星云，属于行星状星云，中心有一颗白矮星。

B 室女座α星中文名是角宿一（Spica），是室女座最亮星。

C “三星正南，家家拜年”指的是猎户座腰带三星（参宿一、参宿二、参宿三）位于正南方时，正值春节前后。

B 古埃及人根据天狼星（Sirius）的偕日升来判断尼罗河洪水期，并据此制定了太阳历。

C 日全食食甚时，月球完全遮住太阳光球层，此时可以观测到日珥（色球层发出的红色火焰状物质）。

C 日晷利用太阳投射的影子来测定时刻，是古代测量太阳时的仪器。

B 北极星视星等约2.0等，在四个选项中最为暗淡；土星最亮时约0.0等、大角星约−0.05等、牛郎星约0.77等，都比北极星亮。

C 木卫三（Ganymede）是伽利略四卫星中直径最大的，也是太阳系中最大的卫星。

D 光年是长度单位（光一年走的距离），天文单位也是长度单位（日地平均距离），两者都是长度单位。

C 双子座的β星北河三（1.14等）比α星北河二（1.58等）更亮，是少见的“β比α亮”的星座。其余三个：室女座α角宿一1.0等远亮于β（3.6等）、天蝎座α心宿二1.06等亮于β（2.6等）、双鱼座α（3.8等）也亮于β（4.5等）。

B M27（哑铃星云）位于狐狸座，是行星状星云，因形状像哑铃而得名。

D 天津四是天鹅座α星，与织女星、牛郎星构成夏季大三角。

A 地内行星指轨道在地球轨道以内的行星，即水星和金星。

D 火星在中国古代被称为”荧惑”，因其荧荧火光、运行无常而得名。

A 光球层是太阳大气最底层，我们平常看到的太阳盘面就是光球层发出的光。

A 只有轨道在地球以内的行星（水星、金星）才能发生凌日现象，金星凌日较为罕见。

C 五帝座一（Denebola）是狮子座β星，位于狮子座尾部。

D 中秋节是农历十五，为满月，满月时月亮在日落时从东方升起。

C 木星是行星，轨道接近黄道面，在黄道上或黄道附近可以看到；北极星靠近北天极，远离黄道。

A 毕宿五是金牛座α星，是金牛座最亮的恒星。

A 太阳和月亮在天空中看起来大小差不多，视直径都约为0.5度，这是日食能够发生的几何条件。

D 恒星颜色反映表面温度，蓝色恒星表面温度高（约10000K以上），红色恒星表面温度较低（约3000-4000K）。

A 月食发生时，地球运行到太阳和月亮之间，三者几乎成一直线，地球在中间。

A 恒星每天提前约4分钟升起，一个月（约30天）提前约120分钟（2小时），所以从22时变为20时。

C 离太阳系最近的恒星是比邻星（半人马座α星C），距离约4.2光年，信号以光速传播需4.2年。

D 星空摄影中，调焦是否精准直接影响星点是否清晰锐利，是决定照片质量最关键的因素。

A 水星和金星没有天然卫星，是太阳系八大行星中唯二没有卫星的行星。

B 金星是太阳系中唯一自转方向与其他大多数行星相反的行星（自东向西自转），称为逆向自转。

C 流星发光高度约80-120公里，民航飞机飞行高度约10公里左右，流星高度约为飞机高度的10倍左右。

C 太阳黑子活动的平均周期约为11年，这是太阳活动最基本的周期。

C 牧夫座与室女座相邻，牧夫座α星大角星与室女座α星角宿一、狮子座的五帝座一构成春季大三角。

A 恒星的周日视运动（东升西落）是地球自西向东自转的反映。

B 心宿二是天蝎座α星，是中国古代二十八宿之一，位于天蝎座的心脏位置。

B 金星表面平均温度约465°C，是太阳系表面温度最高的行星，因其浓厚的二氧化碳大气产生强烈温室效应。

B 小行星带位于火星和木星轨道之间，是太阳系中小行星最密集的区域。

A 水星和金星是地内行星，从地球上看它们与太阳的角距始终不大，不可能在午夜（太阳对跖点方向）经过中天。

C 按黄纬（离黄道面的角距离）比较：大角（牧夫座α）约+30.7°，五车二（御夫座α）约+22.9°，心宿二约−4.6°，角宿一约−2.1°。五车二虽然赤纬最高（+46°），但离黄道并不最远，距黄道最远的是大角。〔注〕官方答案作D（五车二），是按其赤纬高低判断的；按“距黄道最远”的定义应为C。

D 金星是除太阳和月球外天空中自然天体最亮的，最亮时视星等可达-4.7等。

D M45是昴星团（七姐妹星团），位于金牛座，是离地球最近的疏散星团之一。

B 夏季大三角由织女星（0.03等）、牛郎星（0.77等）和天津四（1.25等）组成，织女星最亮。

B 阿波罗（Apollo）是希腊神话中的太阳神，同时主管音乐、诗歌与预言，形象常为手持七弦琴（里拉琴）。阿尔特弥斯是月亮与狩猎女神（阿波罗的孪生姐姐），玛尔斯、维纳斯分别是罗马神话的战神与爱神。

D 老人星（船底座α）赤纬约−52°42′，在北京（北纬约40°）永远升不出地平线，不可能看到。毕宿五约+16°、南河三约+5°、五帝座一约+15°，在北京都能升起。

B 牛郎星（河鼓二）两侧各有一颗暗星（河鼓一、河鼓三），三星几乎排成一线，民间称为“扁担星”——牛郎用扁担挑着一双儿女。天津四是天鹅座α，与人马座、天蝎座都不是这个星群。

B M1蟹状星云位于金牛座，是1054年超新星爆发后留下的遗迹，也是梅西耶星表中的第一号天体。它虽名为“蟹状”，却与巨蟹座无关。

B 南河三（Procyon）是小犬座α星，属小犬座，不属于双子座。双子座的α、β分别是北河二、北河三；另三项（天狼星—大犬座、参宿七—猎户座、轩辕十四—狮子座）都正确。

B 梅西耶马拉松是在一夜之内尽量观测全部110个梅西耶天体的活动，要求太阳位于春分点附近（3月下旬），整夜没有月光干扰，因此3月28日新月前后最合适。7月、11月太阳在黄道另一侧，有大批天体与太阳同升同落，无法在一夜内看全。
