济南 2020年浙江省中小学天文知识竞赛初赛试题

（试题与答案分离版）

【注意事项】请务必仔细阅读！

每位考生拿到一份试卷（共3页）和一张答题卡，考试结束后全部上交。本卷为闭卷考试，考试时间为60分钟。试题全部为选择题，答案必须填涂在规定答题卡上并填上考号，否则无效。每道题答对得4分，答错或多选倒扣2分（得-2分），不答得0分。

本卷为小、初、高三组别的统一试卷，但设定了不同组别的规定题和附加题，分别计分。按规定题的得分数排序决定复赛名单，计入竞赛有效成绩。初赛考试统一不用各类计算器，不允许提前交卷，鼓励积极探索，特殊情况需经监考老师批准，否则作为弃考处理。

本卷共有选择题25+10题，其中：小学组规定题为1-25题、附加题为第26-35题；初中组规定题为第6-30题，附加题1-5和31-35题；高中组规定题为第11-35题，附加题1-10题。试卷满分100+40分。

姓名：__________ 年级：__________ 班级：__________ 得分：__________

第一部分 试题

1. 2020年11月24日4时30分，我国“嫦娥五号”探测器发射圆满成功。这次任务将完成我国“探月工程三部曲”中的（　　）这一步。

A、绕 B、落

C、回 D、探

2. 2020年诺贝尔物理学奖颁给了三位从事黑洞相关研究的天文学家，请问以下四人中（　　）不是今年的获奖者？

A、罗杰·彭罗斯 B、基普·索恩

C、赖因哈德·根策尔 D、安德烈娅·盖兹

3. 下列星座中，（　　）没有一等及以上的亮星？

A、波江座 B、南鱼座

C、长蛇座 D、御夫座

4. 中国古代对木星的称呼是（　　）

A、岁星 B、镇星

C、辰星 D、客星

5. 双子座流星雨通常出现在每年的（　　）月

A、1 B、3

C、8 D、12

6. 天球上的“子午线”是指（　　）

A、过天北极和天顶的一条线 B、东西向的一条线

C、过头顶上的一条线 D、南北向的一条线

7. 哈雷彗星下一次回到地球附近大概要到（　　）年

A、2035 B、2061

C、2112 D、2247

8. 下列选项中距离地表最远的是（　　）

A、流星 B、极光

C、臭氧层 D、夜光云

9. 英仙座对应希腊神话中的哪位英雄人物？（　　）

A、奥德修斯 B、海格力斯

C、珀尔修斯 D、忒修斯

10. 哈勃太空望远镜在距离地表大约559千米的高度围绕地球运行，轨道周期大约（　　）

A、60分钟 B、90分钟

C、120分钟 D、180分钟

11. 秋季星空的标志“秋季四边形”中，四条边上的四颗恒星相互之间（对角的不算）的角距离几乎都是（　　）

A、10° B、15°

C、20° D、25°

12. 事件视界望远镜（EHT）拍摄的黑洞位于（　　）

A、银河系 B、仙女座星系

C、M33星系 D、M87星系

13. 位于智利阿卡塔玛沙漠的ALMA望远镜的工作波段大约在（　　）

A、1nm B、1m

C、1mm D、1cm

14. 下列恒星中温度最低的是（　　）

A、角宿一 B、心宿二

C、南河三 D、天津四

15. 距离太阳系大约25光年的织女星“人”使用望远镜试图寻找太阳周围的行星，在他们看来地球距离太阳的最大角距离约为（　　）秒

A、0.79 B、0.13

C、0.35 D、0.46

16. 下列梅西耶天体中和其他的类型不一致的是（　　）

A、M45 B、M51

C、M34 D、M67

17. 用口径10cm的望远镜不可能看到（　　）

A、木星的伽利略卫星 B、火星极冠

C、金星的相位变化 D、天王星的光环

18. 目前，我国自主研发成功的最大单口径可动式射电望远镜，其最大口径是（　　）

A、305m B、110m

C、70m D、65m

19. 以下关于球状星团的叙述，不正确的是（　　）

A、主要分布在银晕中 B、成员的金属量通常与太阳相当

C、成员星的数量通常可达数十万颗 D、曾在星团中发现过脉冲星

20. 今年诺贝尔物理学奖授予了跟黑洞相关的研究。根据理论物理，不带电也不旋转的黑洞被称为（　　）

A、克尔黑洞 B、雷斯勒-诺德斯特洛姆黑洞

C、史瓦西黑洞 D、克尔纽曼黑洞

21. 我国自行研制的郭守敬望远镜（LAMOST）于2008年建成，下面有关LAMOST的说法错误的是（　　）

A、全称为大天区面积多目标光纤光谱天文望远镜 B、有4000根光纤，是世界上光谱获取效率最高的望远镜

C、利用它发现了人类已知的铁含量最高的巨星（堪称“宇宙最大充电宝”） D、已成为大口径兼大视场光学望远镜的世界之最

22. 如果将太阳系八大行星的公转周期（单位：秒）的对数作为横轴，轨道半长径（单位：米）的对数作为图，可以得到一条直线，请为这条直线的斜率大约是（　　）

A、0.333 B、0.667

C、1 D、1.5

23. 今天（11月28日）的21时，是赤经约为（　　）的恒星中天的时刻

A、1.0h B、1.5h

C、2.0h D、2.5h

24. 下面有关诊断不正确的是（　　）

A、古斯创造了暴胀理论，提出伪真空能量在极秒内的超光速暴胀 B、我们的宇宙的年龄大约是138亿年，因此，宇宙的半径是138亿光年

C、地球上一直无法看到月球的背面，是因为月球的自转周期等于其绕地球的公转周期 D、宇宙的构成中，可见物质仅占约4%，其他都是暗物质和暗能量

25. 在某地夏至的中午观测到太阳高度角大约为80度，请问当地的纬度大约为（　　）

A、10度 B、33度

C、67度 D、80度

26. 火星离地球最近时的角直径为24″，用F为19.5米的折射望远镜所摄得的火星像的直径大致为（　　）毫米

A、13.61 B、8.68

C、2.27 D、0.24

27. 以测量恒星距离和自行为主要目的的天文卫星是（　　）

A、JWST B、HXMT

C、GAIA D、TESS

28. 下列关于椭圆星系的说法错误的是（　　）

A、成员星通常围绕星系中心的特大质量黑洞公转 B、星系中缺乏气体等星际介质

C、成员星通常年龄较大 D、根据哈勃分类法，归类为E0的椭圆星系看起来更接近球体

29. LIGO天文台利用了光的哪种现象对引力波进行探测？（　　）

A、干涉 B、衍射

C、偏振 D、散射

30. 一个双星系统，其主星质量为2倍太阳质量，伴星质量大约为0.5倍太阳质量，其轨道半长径大约为10天文单位。请问这个系统的轨道周期大约为（　　）

A、16年 B、18年

C、20年 D、22年

31. 我国自行研制的500米口径射电望远镜FAST的有效口径大约为300米，其工作波段大约为79MHz~3.0GHz，请问其观测时可达到的最小分辨角大约为（　　）

A、1角秒 B、10角秒

C、1角分 D、1度

32. 由于地球的公转（大约30km/s），在地球上观测到的恒星位置和其实际位置之间会存在一个微小的偏差，被称为光行差。请问在观测北黄极附近的恒星时，这个偏差的大小大约为（　　）

A、0.2角秒 B、2角秒

C、20角秒 D、2角分

33. 以下关于脉冲星的说法，错误的是（　　）

A、首次发现于20世纪60年代，被称为20世纪60年代天文四大发现之一 B、刚被发现的时候，因为被怀疑是外星人发送的信号而被临时命名为“小绿人”

C、系外行星最早是在脉冲星周围发现的 D、脉冲星的发现者乔丝琳·贝尔与其导师休伊什共享1974年诺贝尔物理学奖

34. 2020年10月14日发生了一次火星冲日。火星的轨道周期大约为687天，请问下一次火星冲日发生在（　　）

A、2021年 B、2022年

C、2023年 D、2024年

35. 在地球A处看到一颗流星，高度角为30°，其视星等为0等，在B处的天顶看到同一颗流星。请问在忽略大气消光的情况下，B处看到这颗流星的视星等大约多少（　　）

A、0 B、1

C、-1 D、-1.5

逐题答案与解析

1. C 嫦娥五号完成的是“回”——从月球采样返回。探月工程三步曲：绕（嫦娥一号/二号）、落（嫦娥三号/四号）、回（嫦娥五号）。

2. B 2020年诺贝尔物理学奖获奖者为彭罗斯、根策尔和盖兹。基普·索恩并非该年度获奖者（他于2017年因LIGO获奖）。

3. C 长蛇座没有一等星，其最亮星为长蛇座α（ALPHARD），仅为2等星。

4. A 木星古称岁星，因其约12年绕天一周，古人用以纪年。

5. D 双子座流星雨活跃期在12月4日~17日，极大通常在12月14日前后。

6. A 子午线是过天北极、天顶和天南极的大圆，即南北向的线。

7. B 哈雷彗星周期约76年，上次回归是1986年，下次约在2061年。

8. B 极光出现在约90～400km高度（红色氧原子线可达600km以上），比流星（80～120km）、臭氧层（20～30km）和夜光云（约80km）都高，故选B。

9. C 英仙座对应希腊神话英雄珀尔修斯（Perseus）。

10. B 哈勃望远镜轨道高度约559km，轨道周期约90分钟。

11. B 秋季四边形四边恒星间角距离约为15°。

12. D EHT拍摄的首张黑洞照片来自M87星系中心的超大质量黑洞。

13. C ALMA望远镜工作在毫米/亚毫米波段，约1mm。

14. B 心宿二（天蝎座α）是红超巨星，表面温度约3500K，是选项中最低的。

15. B 地球距太阳1AU，25光年外观测，最大角距离约为0.13角秒。

16. B M45（昴星团）和M34、M67都是疏散星团，M51是旋涡星系，类型不同。

17. D 天王星的光环非常暗弱，10cm口径望远镜无法观测到。

18. D FAST是500米固定式球面望远镜，不能整体转动；我国口径最大的全可动射电望远镜是上海佘山的65米“天马”望远镜（2012年建成），新疆奇台的110米QTT当时还在建设中。故选D。

19. B 球状星团成员星金属量通常远低于太阳，B项错误。

20. C 不带电不旋转的黑洞称为史瓦西黑洞。

21. C C项张冠李戴：“铁含量最高的巨星”并非LAMOST的发现成果。LAMOST全称大天区面积多目标光纤光谱天文望远镜，采用4000根光纤，口径4米、视场5°，是大口径兼大视场光学望远镜的世界之最，A、B、D均正确，故选C。

22. B 由开普勒第三定律 T²∝a³，取对数后斜率=2/3≈0.667。

23. B 11月28日太阳赤经约16h20m，北京时间21时即太阳时角约9h，本地恒星时 LST=太阳赤经+太阳时角=16h20m+9h=25h20m，减去24h得1h20m，即中天恒星的赤经约1h20m（≈1.5h）。故选B。

24. B B项错误——宇宙年龄138亿年，但可观测宇宙半径约465亿光年（因宇宙膨胀），不是138亿光年。

25. B 夏至正午太阳高度 h=90°−|φ−23.5°|=80°，得 |φ−23.5°|=10°，即 φ=33.5°N 或 13.5°N；选项中只有33°与之相符（10°偏差过大），故选B。

26. C 像直径=角直径×焦距=24″×(19.5m/206265″)≈2.27mm。

27. C GAIA卫星主要任务是精确测量恒星位置和自行。

28. A 椭圆星系成员星并非围绕中心黑洞公转，A项错误。

29. A LIGO利用光的干涉现象探测引力波。

30. C 由开普勒第三定律（用太阳为单位的调和形式）T²=a³/(M₁+M₂)=10³/2.5=400，故 T=20 年。故选C。

31. C 分辨角≈1.22λ/D，取工作波段，最小分辨角约1角分。

32. C 光行差常数≈v/c≈30/300000=10⁻⁴弧度≈20.6角秒，取整约20角秒。

33. D 1974年诺贝尔物理学奖授予休伊什和赖尔，实际首先认出脉冲星信号的乔丝琳·贝尔并未获奖，故D说法错误；脉冲星1967年发现、属60年代四大发现之一，曾因信号极规律被称为“小绿人”（LGM-1），系外行星也最早在脉冲星PSR B1257+12周围发现，A、B、C均正确。故选D。

34. B 火星会合周期≈1/(1/365.25-1/687)≈780天≈2.14年，2020+2.14≈2022年。

35. D 忽略大气消光时，恒星的亮度只取决于距离。A处天顶距60°，到流星的距离是B处（天顶）的1/cos60°=2倍，亮度按距离平方反比减弱为1/4，即暗2.5lg4≈1.5等；B处看到的星等为0−1.5=−1.5等。故选D。
