一、单选题答案（共50题）

1. B 光年是长度单位，指光在真空中一年所走的距离，约9.46万亿千米。

2. A 日食只可能发生在农历初一（朔日），此时月球位于太阳和地球之间。

3. C 水星是太阳系八大行星中体积和质量最小的行星。

4. C 小熊座位于北天极附近，属于拱极星座，在北京全年可见。

5. B 周年视差是由地球绕太阳公转引起的恒星位置周年性微小变化。

6. B 截至2026年6月，土星已确认卫星293颗（2023年新增64颗、2025年3月新增128颗、2026年3月新增11颗），远多于木星的115颗，是太阳系卫星最多的行星。

7. C 天狼星是大犬座α星，是夜空中除太阳外最亮的恒星，视星等为-1.46等。

8. C 织女星即天琴座α星，是夏季大三角的顶点之一。

9. B 牛郎星即天鹰座α星，与织女星隔银河相望，是夏季大三角的另一顶点。

10. B 水星是离太阳最近的行星，海王星是离太阳最远的行星。

11. A 月食发生时，地球运行到太阳和月球之间，地球的影子投射到月球上。

12. C 月球绕地球公转一周约为27.3天（恒星月），约一个月。

13. A 流星体进入地球大气层后，与大气剧烈摩擦燃烧发光，形成流星尾迹。

14. B 所有恒星都在宇宙中高速运动，只是因距离太远，肉眼难以察觉其位置变化。

15. B 大熊座（含北斗七星）是北天拱极星座，全年可见。

16. B 小行星带位于火星和木星轨道之间，是太阳系小行星最密集的区域。

17. A 水星和金星是太阳系中仅有的两颗没有天然卫星的行星。

18. B 金星自转方向与其他行星相反（自东向西，逆向自转），且自转周期长达243天，比公转周期还长。（天王星自转轴倾斜约98°，也呈逆向自转，但本题各选项中只有金星符合。）

19. A 海王星才是距离太阳最远的行星，天王星排第七。海王星也有光环，天王星因侧躺自转有四季，海王星是远日行星中体积最小的。

20. D 纪限仪是一种天文观测仪器，用于测量天体之间的角距离，不是计时仪器。

21. C 现在的北极星是小熊座α星（勾陈一），位于小熊座尾部末端。

22. D 月球表面布满环形山（陨石坑），这是月球最显著的地貌特征，由陨石撞击形成。

23. B 脉冲星是高速旋转的中子星，主要由中子构成，密度极高。

24. D 下弦月出现在农历廿二、廿三，于下半夜从东方升起，黎明前位于南部天空。

25. C 中秋节是农历八月十五，此时月球位于地球外侧，太阳照射面完全朝向地球，为满月。

26. B 太阳直径约139万千米，地球直径约1.27万千米，两者比值约109，最接近100倍。

27. C 1928年国际天文学联合会将全天划分为88个星座。

28. B 1969年7月20日，阿姆斯特朗乘坐阿波罗11号登月，成为第一个踏上月球的人。

29. D 心宿二（天蝎座α星）是一颗红超巨星，呈现出明显的红色光芒。

30. A 电影《星际穿越》中描述的具有极强引力、连光都无法逃脱的天体是黑洞。

31. C 风暴洋（Oceanus Procellarum）是月球正面最大的月海，面积广阔。

32. B 太阳光到达地球约需8分20秒，即约8分钟。

33. B 土星的平均密度只有约0.69 g/cm³，比水还小，是八大行星中密度最小的；木星约1.33、天王星约1.27、海王星约1.64 g/cm³。

34. C 纬度越低，被地平线挡住的星空越少：在赤道附近一年中能看到全部88个星座，中纬度约能看到60多个，高纬度更少。

35. C 6月包含夏至（6月21日或22日），此时北半球白昼最长、黑夜最短。

36. A '朔'指月球运行到太阳和地球之间，其暗面朝向地球，对应农历每月初一。

37. B 夏季大三角由织女星（天琴座）、牛郎星（天鹰座）和天津四（天鹅座）组成。心宿二属于天蝎座。

38. C 镜头应使用专用镜头布轻轻擦拭，严禁用纸巾、手指或水直接接触镜头，以免划伤或损坏镀膜。

39. C 公历闰年规则：能被4整除但不能被100整除，或能被400整除。2100能被100整除但不能被400整除，故不是闰年。

40. A 行星距离较近，视圆面而非点光源，因此星光不受大气扰动影响，看起来稳定不'眨眼'。恒星则因是点光源而闪烁。

41. C 月环食不可能发生。因为地球的本影锥远大于月球直径，月球进入地球影子时要么全入（月全食）要么部分入（月偏食），不会出现环食。

42. A 北京位于乌鲁木齐以东，地球自西向东自转，东边城市先看到日出。

43. B 傅科摆的摆动平面在缓慢旋转，直观证明了地球的自转。

44. C 南北半球季节相反。北半球6月为夏季时，南半球为新西兰的冬季。

45. C 四季交替由地球公转和地轴倾斜共同造成，与地球自转（昼夜交替）无关。

46. A 6月南极圈内处于极夜，太阳整日位于地平线以下，不可能“艳阳高照”；正因为是漫漫长夜，反而能看到满天星斗。

47. C 地球绕太阳公转一周约365.25天，即一年。

48. B 哥白尼在《天体运行论》中提出日心说，认为地球绕自身轴自转并绕太阳公转。

49. C 四季交替是由地轴倾斜造成的。若地轴不倾斜，则不会有四季变化，但昼夜交替仍会存在。

50. A 极昼是极地地区太阳24小时不落的自然现象，发生在夏季的极地区域。
