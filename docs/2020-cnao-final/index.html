II. 简答题

14. （仅低年组）土星环缝

土星环是太阳系八颗行星中最突出的行星环，土星环中存在由于共振而产生的缝隙，其中最为明显的是卡西尼环缝。假设我们将发射一个探测器来近距离观测土星环缝的结构，其角分辨率为5 arcsec，探测器与土星之间最近的距离为825000km，请问该探测器能够探测的土星光环的最窄缝隙为多大？

15. （仅高年组）主序星占比

假设诞生的恒星中最大和最小质量分别是100和0.08个太阳质量，依据Salpeter初始质量函数估算银河系中类太阳G型主序星占多少比例。

提示：Salpeter初始质量函数是 dN/dM = kM^(-α)，这里k是归一化常数，指数α=2.35。

对上式积分可以得到 N = k/(α+1) × [M^(α+1)]，这里M_lower和M_upper分别代表最小恒星质量0.08和最大恒星质量100。

16. （低年组和高年组）灶神星冲日

对于地球来说，当行星或小行星运行到与太阳相反的方向时，我们称其为冲日。对于火星或者小行星带的天体，由于距离地球较近，近日点的冲日就会比一般的冲日更亮，也就是所谓的"大冲"。灶神星（Vesta）是小行星带中最大的成员之一，它于1807年3月29日被德国天文学家奥伯斯发现。灶神星的近日点和远日点分别为2.151AU和2.572AU。上次大冲发生在2018年6月20日，视星等达到5.1等。假设灶神星轨道和地球轨道共面，且其轨道不受火星和木星的影响。

(1) 计算下次仍然发生在5-6月左右的大冲的年月日。

(2) 计算灶神星在远日点冲日时的视星等。

17. （低年组和高年组）脉冲星

射电脉冲星绝大多数都是孤立的中子星，而X射线脉冲星绝大多数都是一个中子星和一个正常的光学伴星组成的双星系统，中子星通过引力吸积光学伴星的物质发射强烈的X射线辐射。如果中子星的质量约为1.4个太阳质量，求X射线脉冲星的最大可能光度。

提示：X射线脉冲星的辐射（光）照射物质的时候，会对被照射的物质产生向外的辐射压力，当辐射压力超过中子星引力的时候，脉冲星就不能吸积物质了。

辐射压力 F = Lσ/(4πc r²)，其中L是脉冲星的光度，光散射截面σ = 6.7×10⁻²⁵ cm²。

18. （低年组和高年组）新智彗星颗粒的命运

2020年的新智彗星（Neowise）吸引了无数眼球。一般彗星会释放出不同尺寸的颗粒，假设一个脱离了彗核的彗星颗粒（其尺寸为D）在太阳系内只受到太阳的万有引力和太阳辐射压力的作用，则存在一个彗星颗粒临界尺寸D₀，使得该颗粒受到的引力和辐射压力平衡，请估算D₀的值，并说明尺寸大于D₀和小于D₀的Neowise彗星颗粒的命运将分别是什么？

选择题逐题解析

1.（仅低年组）答案：A 月球绕地球公转方向为自西向东，因此月球相对背景恒星的运动方向也是自西向东。

2.（仅低年组）答案：C 银河系约有1000亿~4000亿颗恒星，即约10×10¹⁰颗，故选C。

3.（仅低年组）答案：C 正方案是中国古代专门用来测定方向的仪器。日晷主要测定时间，圭表主要测定节气，水运仪象台是综合天文仪器。

4. 答案：C 北黄极在赤道坐标系中的位置约为赤经18h 00m，赤纬+66°34′。

5. 答案：C 天问一号的祝融号火星车设计寿命为90个火星日，约92个地球日。

6. 答案：C 宇宙的演化顺序是：大爆炸 → 暴胀（约在大爆炸后10⁻³⁶秒，宇宙急剧膨胀）→ 黑暗时代（宇宙充满中性气体、还没有恒星发光）→ 第一代恒星和星系点亮宇宙（再电离），故选C。

7. 答案：B M87是室女座星系团的核心星系，不属于本星系群。M110、M33、M32均为本星系群成员。

8. 答案：D 脉冲星可以作为“宇宙时钟”：长期计时观测脉冲到达时间，可探测纳赫兹引力波（脉冲星计时阵）、检验广义相对论、用于深空导航（如XNAV），但从未用于寻找地外生命，故选D。

9. 答案：B 参宿四是红超巨星，温度较低，B-V色指数较大；参宿七是蓝超巨星，温度较高，B-V较小。

10. 答案：D 恒星光谱谱线宽度受压力增宽（碰撞增宽）和多普勒增宽（热运动）等多种因素影响。

11.（仅高年组）答案：A 宇宙中按质量比，最丰富的元素是氢，其次为氦，第三为氧。

12.（仅高年组）答案：B 月球本影在地面上自西向东扫过，中纬度地区影子的移动速度约每秒1千米，一条全食带往往长达成千上万千米，因此最东端的食甚要比最西端晚几个小时，约3小时，故选B。

13.（仅高年组）答案：C L_Edd = 1.26×10³⁸ × 10⁹ = 1.26×10⁴⁷ erg/s，爱丁顿比率 = 10⁴⁷ / 1.26×10⁴⁷ ≈ 0.79。

简答题解析

14.（仅低年组）土星环缝

角分辨率 θ = 5 arcsec = 5/206265 rad

最小可分辨缝隙 = d × θ = 825000 × (5/206265) ≈ 20.0 km

答：该探测器能够探测的最窄缝隙约为20 km。

15.（仅高年组）主序星占比

Salpeter初始质量函数：dN/dM = kM^(-2.35)

总恒星数 N_total = ∫(0.08→100) kM^(-2.35) dM = k/1.35 × (0.08^(-1.35) - 100^(-1.35))

G型主序星（质量约0.8~1.2 M☉）数 N_G = k/1.35 × (0.8^(-1.35) - 1.2^(-1.35))

计算：0.8^(-1.35) ≈ 1.352，1.2^(-1.35) ≈ 0.782，0.08^(-1.35) ≈ 30.28，100^(-1.35) ≈ 0.002

N_total ∝ 30.28 - 0.002 ≈ 30.28

N_G ∝ 1.352 - 0.782 = 0.570

比例 = 0.570/30.28 ≈ 0.0188 ≈ 1.9%

答：银河系中类太阳G型主序星约占1.9%。

16.（低年组和高年组）灶神星冲日

(1) 灶神星轨道半长轴 a=(2.151+2.572)/2=2.3615AU，轨道周期 T=a^1.5≈3.63年，与地球的会合周期 S=1/(1−1/3.63)≈1.38年≈504天。 因此每过504天就有一次冲日，而每过一个会合周期，冲日时太阳的黄经向后推进约(504−365.25)×0.9856°≈137°，冲日的公历日期大约推后4.6个月：2018-06-20 → 2019-11 → 2021-03 → 2022-08 → 2023-12 → 2025-05。 灶神星近日点黄经约255°，“大冲”要求冲日时它的日心黄经接近255°，即太阳黄经接近75°（5月中旬）。2025年5月中旬那次冲日，太阳黄经约53°、灶神星日心黄经约233°，与近日点只差20多度，是2018年之后下一次落在5—6月的大冲。 答：下次仍发生在5—6月左右的大冲约在2025年5月15日前后（其间的2019年11月、2021年3月、2022年8月、2023年12月各次冲日都不在5—6月）。

(2) 近日点冲日时：d_日 = 2.151 AU，Δ_日 = 2.151 - 1.0 = 1.151 AU，m = 5.1

绝对星等 H = 5.1 - 5log(2.151) - 5log(1.151) ≈ 5.1 - 1.66 - 0.31 = 3.13

远日点冲日时：d_远 = 2.572 AU，Δ_远 = 2.572 - 1.0 = 1.572 AU

m_远 = 3.13 + 5log(2.572) + 5log(1.572) ≈ 3.13 + 2.05 + 0.98 = 6.16

答：远日点冲日时灶神星的视星等约为6.2等。

17.（低年组和高年组）脉冲星

X射线脉冲星的最大光度为爱丁顿光度。

由 F_rad=F_grav：Lσ/(4πcr²)=GM·m_p/r²（每个散射电子对应约一个质子质量），得 L_Edd=4πGMc·m_p/σ。

L_Edd = 1.26×10³⁸ × (M/M☉) erg/s

M = 1.4 M☉

L_max = 1.26×10³⁸ × 1.4 = 1.764×10³⁸ erg/s

答：X射线脉冲星的最大可能光度约为1.76×10³⁸ erg/s。

18.（低年组和高年组）新智彗星颗粒的命运

辐射压力 F_rad = L☉ × σ_geo / (4πc r²)，其中 σ_geo = πD²/4 为几何截面

万有引力 F_grav = G M☉ m / r² = G M☉ × (π/6)ρD³ / r²

令 F_rad = F_grav：

L☉ × πD²/4 / (4πc r²) = G M☉ × (π/6)ρD³ / r²

L☉ / (16c) = G M☉ × ρ × D₀ / 6

D₀ = 3L☉ / (8πc G M☉ ρ)

代入 L☉ = 3.828×10³³ erg/s，M☉ = 1.989×10³³ g，ρ ≈ 1 g/cm³：

D₀ ≈ 1.1 μm

答：临界尺寸D₀约为1微米（约1.1μm）。由于辐射压力正比于截面（∝D²）、引力正比于质量（∝D³），两者之比 β=F_rad/F_grav∝1/D：尺寸大于D₀的颗粒 β<1，引力占主导，留在绕日轨道上，并在坡印廷—罗伯逊阻力作用下缓慢螺旋落向太阳；尺寸小于D₀的颗粒 β>1，会被辐射压力加速到超过逃逸速度，最终被推出太阳系成为星际尘埃。这也正是彗星尘埃尾总是背离太阳的原因。
