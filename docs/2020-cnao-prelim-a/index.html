【注意事项】请务必仔细阅读！

1. 每位考生会拿到一张预赛试卷和一张答题卡。

2. 低年组考生（指2005年1月1日以后出生，并且没有参加过国际天文奥赛IAO和亚太天文奥赛APAO的考生）只答本卷的01-30题，高年组考生只答06-35题。

3. 本卷为闭卷考试，请答卷人按照自己的真实水平独立完成答卷，并认真、完整地用签字笔在试卷上填写有关信息并签字，用2B铅笔在答题卡上按要求签名（应与试卷上的签名一致；签名明显不一致的取消参赛资格），填涂试卷类型（见本注意事项之前的表格第二列）、准考证号（在空格处写数字，并填涂每个数字下面对应的部分）、组别，以及每道题的答案。未按要求填涂的取消考试成绩。考试开始30分钟之后才可交卷，并在不影响其他考生答题的情况下安静离开考场，否则取消考试成绩。在监考老师宣布考试结束时，该考场所有考生应停止答卷，将试卷和答题卡放在桌上，保持安静离开考场。

4. 每题选择一个最接近正确的答案。将对应的字母（A，B，C，D之一）填涂在答题卡该题号下方的对应处。不会做的题目不选。已填涂的答案如需改正，请用橡皮将原答案尽量擦除干净。每道题答对得4分，答错或多选得-4分，不选得0分。满分120分。草稿可写在试卷“草稿区”处。

逐题答案与解析

01. C

解析：参宿四（Betelgeuse）是猎户座α星，位于猎户座。

02. D

解析：金星西大距时，从金星上看地球处于方照位置。

03. A

解析：Ia型超新星由于白矮星吸积达到钱德拉塞卡极限后爆发，峰值亮度较为一致，被称为“标准烛光”。

04. C

解析：三垣指紫微垣、太微垣、天市垣，军市垣不属于三垣。

05. A

解析：星等差公式：m₁-m₂ = -2.5lg(N₁/N₂)，1000颗6等星叠加：m = 6 - 2.5×lg1000 = 6 - 7.5 = -1.5。

06. C

解析：太阳绝对星等约4.8等，与天狼星1.5等之差为4.8-1.5 = 3.3等。

07. D

解析：上中天是天体经过观测者子午圈时地平高度达到最大值的位置。

08. A

解析：2019年诺贝尔物理学奖一半授予皮布尔斯表彰他对宇宙学结构、历史的新理解。

09. A

解析：星像在视场中的漂移由极轴偏差引起。对正东方地平附近的恒星，高度方向的偏差只造成南北向漂移——极轴偏高时星像向北漂，偏低时向南漂；对正南子午圈附近的恒星，同样的偏差只造成东西向漂移，故南北向几乎不动（说明没有方位偏差）。现向东观测时星像北漂，说明极轴指向偏高，选A。

10. C

解析：①错：受大气折射与太阳视半径影响，春分日白昼约12小时07分，并非整12小时；②错：只有北回归线以北，夏至日正午太阳高度才全年最高，赤道到北回归线之间最大值出现在太阳直射当地纬度的那两天；③对：秋分日太阳赤经约12h，地方恒星时=太阳时角+赤经=时角+12h，恰等于真太阳时，差值仅数秒；④错：北京日落最早在12月上旬（约12月8日），冬至日反而略晚。故1对3错，选C。

11. B

解析：火星轨道半径1.52au，观测基线更长，周年视差约为地球上的1.52倍（更大）；火星公转速度约24.1km/s，小于地球的29.8km/s，光行差常数随之变小（约16.5″，地球为20.5″）。故火星上视差大、光行差小，选B。

12. C

解析：有效温度约5500K对应G型星，质量约1个太阳质量，主序寿命约100亿年。

13. C

解析：视直径∝行星半径÷与木星的距离。取最近距离：水星2440/4.81≈507、金星6052/4.48≈1350、地球6371/4.20≈1517、火星3390/3.68≈921（km/au），地球的视直径最大，选C。

14. B

解析：M15是球状星团，球状星团的特点是低金属丰度且年老。

15. C

解析：开普勒第三定律：T² = a³，T=7000年，a = T^(2/3) = 7000^(2/3) ≈ 360 au。

16. B

解析：距离模数 m-M = 5lg(d/10pc) = 5lg(1000kpc/10pc) = 5lg(100000) = 25，m = -8 + 25 = 17，取最接近的18。

17. A

解析：SpaceX的Starlink（星链）卫星首批60颗于2019年5月发射。

18. B

解析：二十四节气是根据太阳在黄道上的视运动（即地球公转）制定的。

19. C

解析：开普勒望远镜成倒立像（相当于把物旋转180°）。在物镜与目镜之间插入凹透镜就是巴洛镜，作用是提高倍率，不改变像的倒正，所以仍是倒像：字母p旋转180°后为d，选C。

20. D

解析：昴星团赤经约3h47m。农历十六为望，月亮与太阳赤经相差约12h，月亮要掩昴星团就必须位于赤经约3h47m处，此时太阳赤经约15h47m，对应太阳黄经约236°，即11月中下旬才会出现，选D。

21. A

解析：臭氧分子O₃在9.6μm红外带和紫外哈特莱带有很强的吸收，而且O₃只能由生物来源的O₂经光化学过程形成，是判定类地生命最显著的标志，选A。

22. B

解析：暴胀理论是大爆炸宇宙学理论的延伸和补充，本身不是直接观测证据。

23. B

解析：鲍里索夫彗星（2I/Borisov）是已确认的第二个星际天体（第一个是‘奥陌陌’）。

24. B

解析：先由四条谱线定红移：492/410=1.200、521/434=1.201、583/486=1.199、787/656=1.200，故z≈0.20。谱线红移属相对论性多普勒效应，v/c=[(1+z)²−1]/[(1+z)²+1]=(1.44−1)/(1.44+1)=0.44/2.44≈0.18，选B。（若误用v=zc会得0.20而错选C。）

25. B

解析：选项B错误，实际观测表明宇宙膨胀速度比预测的要快（哈勃常数危机），而非更慢。

26. A

解析：根据赫罗图，红超巨星位于右上角，半径最大（比蓝超巨星和红巨星都大）。

27. D

解析：宇宙微波背景辐射的谱线轮廓是完美的黑体谱，温度约2.725K。

28. B

解析：由L∝R²T⁴，温度相近时L∝R²，R₁/R₂ = √(82) ≈ 9.1。

29. C

解析：核时标 τ ∝ M/L，τ = 2.5×10¹⁰ × (10/300) = 2.5×10⁹ × (1/3) ≈ 8.3×10⁸年。

30. D

31. A

解析：九个星中赤纬最高的是天津四（天鹅座α，+45.3°），距北天极约44.7°；织女星+38.8°（51.2°）、大角星+19.2°（70.8°）、参宿四+7.4°（82.6°）。故天津四与北天极角距离最小，选A。

32. A

解析：岁差在中国古代由东晋虞喜独立发现，称为“岁差”。

33. C

解析：银河系约2000亿颗类太阳恒星，总绝对星等M≈4.83−2.5lg(2×10¹¹)≈−23.4；超新星峰值比星系整体亮3等（19→16），故峰值M≈−26.4。前身星（类参宿四）M=−5，两者光度比=10^[(−5+26.4)/2.5]≈10^8.6≈4×10⁸，最接近10⁸，选C。

34. D

35. B
