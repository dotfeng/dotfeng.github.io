一、单项选择题（共35题，每题2分，满分70分）

1. 中国第一颗月球探测卫星“嫦娥一号”的发射日期是（　　）。

(A)2006年10月30日 (B)2007年4月15日(C)2007年10月24日 (D)2008年2月22日

2. 伽利略的国籍是（　　）。

(A)美国 (B)德国(C)荷兰 (D)意大利

3. 对于地球上的观测者，肉眼可见的恒星大概是（　　）颗。

(A)6000 (B)12000(C)24000 (D)36000

4. 岁星指的是（　　）。

(A)水星 (B)金星(C)木星 (D)土星

5. 小明晚上在阳台观星时发现有一个亮点儿在星空中划过，亮度逐渐变亮，达到最亮时突然完全消失，整个过程持续了2分钟左右。小明看到的最可能是（　　）。

(A)UFO (B)国际空间站(C)流星 (D)彗星

6. 中国天文日是每年的（　　）。

(A)3月3日 (B)5月19日(C)8月15日 (D)10月30日

7. 到目前为止在中学阶段获得小行星命名的中国学生大约有（　　）。

(A)1人 (B)3-5人(C)10人左右 (D)超过20人

8. 在2007年的IAO，IOAA和APAO三大国际天文奥林匹克竞赛中，中国选手总共获得（　　）块奖牌。

(A)7 (B)15(C)28 (D)34

9. 人类宇航员第一次进行太空漫步的时间是（　　）年。

(A)1965 (B)1978(C)1992 (D)2003

10. 近年发现的被称为“世纪大彗星”的彗星的编号是（　　）。

(A)17P/Holmes (B)C/2006P1麦克诺特(C)P/2007R5SOHO (D)C/2007T1麦克诺特

11. 2007年10月24日在（　　）座有一颗彗星亮度突然增亮100万倍左右。

(A)天鹅 (B)英仙(C)御夫 (D)船帆

12. 下述2007年的四次天象在中国观测不到的是（　　）。

(A)3月4日月全食 (B)3月19日日偏食(C)8月28日月全食 (D)9月11日日偏食

13. 太阳的直径相比于地球到月球的距离（　　）。

(A)远大于地月距离 (B)大约是地月距离的4倍(C)大约是地月距离的1/20 (D)远小于地月距离

14. 使用地面光学望远镜观测多数近地小行星的最佳时机一般是当它位于（　　）附近的时候。

(A)近日点 (B)近地点(C)冲日 (D)大距

15. 在澳大利亚的悉尼市当地时间中午12点面向太阳站立，太阳未来一小时的视运动方向是（　　）。

(A)向东 (B)向南(C)向西 (D)向北

16. 后发座流星雨发生在每年的（　　）月。

(A)3 (B)6(C)9 (D)12

17. 显微镜座距离地球的距离是（　　）。

(A)小于20光年 (B)33光年(C)大于50光年 (D)没有意义

18. 在月球表面的宇航员肯定看不到的是（　　）。

(A)地偏食 (B)日偏食(C)日环食 (D)日全食

19. 与中国传统的24节气关系最大的是（　　）。

(A)月球自转 (B)月球公转(C)地球自转 (D)地球公转

20. 在我国北方地区流传的“三星正南，家家拜年”说的是某天北京时间（　　）时左右的天象。

(A)0 (B)3(C)18 (D)21

21. 在一年时间里，地球上的观测者能够看到的月面部分占实际月球表面的约（　　）%。

(A)50 (B)60(C)80 (D)100

22. 以下没有在2007年发生的天文事件是（　　）。

(A)第二届国际路边天文之夜活动 (B)金秋览月活动(C)北京天文馆建馆50周年 (D)中国自然科学博物馆协会天文馆专业委员会成立

23. 以下有关2007年的哪条天文新闻说的有错误（　　）。

(A)3月份叶泉志获得苏梅克近地天体奖 (B)7月份叶泉志、林启生发现鹿林彗星(C)9月份日本成功发射了一颗月球探测卫星 (D)12月份陈滔、高兴发现陈-高彗星

24. 一位天文系的老师晚上在天文台观测，把自己的手表调成了恒星时，但忘了在观测结束的时候调回去。结果他第二天上课的时候迟到了半个小时。这件事儿发生在某年的（　　）月。

(A)3 (B)6(C)9 (D)12

25. 假设天气晴朗，2008年的以下日期中最适于梅西叶天体马拉松的观测的是（　　）。

(A)2月7日 (B)3月21日(C)4月22日 (D)5月17日

26. 以下地方的射电天文望远镜没有参与嫦娥一号的定轨观测的是（　　）。

(A)北京密云 (B)上海佘山(C)云南昆明 (D)青海德令哈

27. 以下命题比较正确的是（　　）。

(A)流星体受地球引力作用坠入地球大气层产生流星现象 (B)月球只能挡住极小比例的撞向地球的流星体(C)多数的火流星发生时伴有声音或产生碎裂的现象 (D)多数的火流星会伴随陨石的降落事件

28. 以下哪两个星座不是相邻的星座（　　）。

(A)白羊座和三角座 (B)天琴座和天鹰座(C)双子座和猎户座 (D)仙女座和飞马座

29. 口径相同的两台折射望远镜焦距分别是600毫米和1000毫米，分别配置焦距15毫米和25毫米的目镜，这两台望远镜观测效果最有可能不同的是（　　）。

(A)倍数 (B)分辨率(C)视场 (D)极限星等

30. 与北京和兴隆相比，在南极冰穹A开展光学天文观测的不利之处是（　　）。

(A)温度太低 (B)连续可观测时间短(C)可观测天体范围小 (D)大气宁静度不好

31. 以下四位观测者都报告说在11月下旬的某天的一个小时的时间里观测到3颗狮子座流星雨的群内流星。谁的报告最不可信？（　　）

(A)北京时间16日凌晨2-3时，在天津 (B)北京时间19日23-24时，在乌鲁木齐(C)北京时间22日早上6-7时，在北京 (D)世界时24日18时，在悉尼（东经151度，南纬34度）

32. 以下星座中距离M13角距离最近的是（　　）座。

(A)天琴 (B)飞马(C)双鱼 (D)狮子

33. 以下梅西叶天体里距离地球最远的是（　　）。

(A)M22 (B)M31(C)M42 (D)M45

34. 月全食发生在农历正月十五附近的概率是（　　）。

(A)大于或等于1/2 (B)1/10左右(C)1/1000左右 (D)小于十万分之一

35. 某彗星的近日距和远日距分别约为1天文单位和10万天文单位。它绕太阳一圈的时间约为（　　）万年。

(A)小于1 (B)10(C)100 (D)1000

逐题答案与解析

1. C 嫦娥一号于2007年10月24日18时05分由长征三号甲火箭在西昌卫星发射中心发射。

2. D 伽利略是意大利人，他最早用望远镜系统观测天体，被称为“现代观测天文学之父”。

3. A 全天肉眼可见的恒星约6000颗，任一时刻地平之上大约只能看到3000颗。

4. C 岁星即木星。古人发现木星约12年绕天一周（实际11.86年），每年镇守一个星次，故称岁星。

5. B 一个亮点能持续约2分钟、缓慢移动、亮度渐亮并在最亮时突然消失——这是国际空间站过境并进入地球地影的典型特征：空间站过境可持续2~6分钟，进入地影后会在几秒内迅速变暗“消失”；流星从出现到熄灭只有零点几秒到几秒钟，彗星在星空中几乎不动，UFO不属于天文解释。故选B。

6. D 中国天文日定在每年10月30日。1922年10月30日，中国天文学会在北京古观象台（当时为中央观象台）召开成立大会，这是我国现代天文学事业起步的标志；1992年起设立“中国天文日”以资纪念，同时作为面向公众的天文科普日。

7. D 国际天文奥林匹克竞赛（IAO）等赛事有给获奖选手命名小行星的传统，自1990年代中期中国组队参赛以来，历届获得奖牌的多位中学生先后得到小行星命名，到2008年累计已超过20人（另有叶泉志等中学生通过发现小行星获得命名权）。故选D。

8. C 2007年中国选手在第12届IAO、第1届IOAA和第3届APAO三项赛事中合计获得28枚奖牌，其中在厦门举行的第3届亚太天文奥赛获奖最多。

9. A 1965年3月18日，苏联宇航员列昂诺夫走出上升2号飞船，完成了人类第一次太空漫步。

10. B 2007年1月过近日点的麦克诺特彗星（C/2006 P1）亮度达-5等以上，白天都能看到，被称为“世纪大彗星”。

11. B 2007年10月24日，周期彗星17P/Holmes在英仙座突然爆发，亮度从17等猛增到2.5等，增亮约100万倍。

12. D 9月11日的日偏食只发生在南美洲南部，中国完全看不到；3月19日的日偏食、8月28日的月全食我国都能看到，3月4日月全食在我国西部月落前也有部分可见。

13. B 太阳直径约139万km，地月距离约38万km，两者之比约3.7，即太阳直径约为地月距离的4倍。

14. C 近地小行星在冲日前后离地球最近、整夜可见，且相位最圆，是地面光学望远镜观测的最佳时机。

15. C 悉尼位于南半球，正午太阳在正北方。面向太阳站立时，太阳因地球自转自东向西移动，一小时内的视运动方向是向西（即向观测者的左侧）。

16. D 后发座流星雨是小流量流星雨，活跃期在12月中旬前后，极大在12月16日左右。

17. D 星座只是天球上的区域划分，成员星彼此相距悬殊（显微镜座最亮星α约33光年，暗星可达上千光年），谈“星座的距离”没有意义。

18. C 从月球看，地球的角直径约1.9°，远大于太阳的0.5°，地球总能把太阳整个遮住，只会发生日全食（以及初亏、复圆的偏食阶段），不可能出现日环食。

19. D 24节气按太阳在黄道上的位置（黄经每15°一个节气）划分，本质反映的是地球公转造成的太阳直射点变化。

20. D 猎户座“三星”（参宿一、二、三）赤经约5h35m。春节期间它们上中天（正南）大约在21~22时，故“三星正南，家家拜年”说的是21时前后的天象。

21. B 由于月球天平动，地球上的观测者一年中累计能看到月面的约59%，接近60%。

22. A 本题按原卷答案为A。北京天文馆1957年9月建成开放，2007年恰是建馆50周年；金秋览月、天文馆专业委员会成立也都是2007年的事。

23. D 陈-高彗星（C/2008 C1）是2008年2月1日由陈韬、高兴发现的，不在2007年；日本“月亮女神”确实在2007年9月14日发射成功，叶泉志获苏梅克近地天体奖、叶泉志与林启生发现鹿林彗星也都是2007年的事。

24. C 恒星时与地方时之差约等于“太阳赤经-12h”。手表的恒星时读数比实际时刻快半小时，说明当时太阳赤经约11h30m，对应9月中旬（秋分前一周多）。

25. A 梅西耶马拉松必须在无月夜进行。2008年2月7日恰为朔（新月），而3月21日是望（满月）、4月22日和5月17日也都接近满月，月光会淹没暗弱天体。

26. D 嫦娥一号的VLBI测轨网由上海佘山、北京密云、云南昆明、乌鲁木齐四个站组成，青海德令哈站不在其中。

27. B 月球截面只有地球的约1/13，又被地球引力聚焦“抢走”大部分来客，只能挡住极小比例的流星体。A的“坠入”说法错（流星体是靠高速运动闯入，而非被引力吸下来）；C的“伴有声音”若指同时听到则错；D多数火流星并没有陨石落地。

28. B 天琴座与天鹰座之间隔着天鹅座、武仙座（以及天箭座、狐狸座），并不相邻。白羊座与三角座、双子座与猎户座、仙女座与飞马座都是相邻星座。

29. C 600÷15=40倍，1000÷25=40倍，两者放大倍数相同；口径相同则分辨率、极限星等也相同，唯一明显不同的是视场——焦距短的600mm那台视场更大。

30. C 冰穹A位于南纬约80°，只能观测赤纬约-10°以南的天区，北天绝大部分天体永远看不到，可观测天体范围小。低温是工程上的困难，极夜恰好带来连续数月的可观测时间，大气宁静度也极好，这几点都不是观测上的“不利”。

31. B 11月下旬狮子座流星雨的辐射点在赤经约10h、赤纬+22°。乌鲁木齐（东经88°）当地21时30分时，辐射点还在地平线以下约12°，不可能在一小时内看到3颗群内流星。

32. A M13位于武仙座，与天琴座的边界只相距几度；飞马座、双鱼座、狮子座都在30°以上。

33. B M31距离约254万光年，是四个选项中最远的；M22约1万光年、M42约1340光年、M45约440光年。

34. B 月食只能发生在望日且月球靠近黄白交点，而正月十五恰好落在交点附近的概率约为十分之一，所以元宵节月全食虽不罕见但也并不常有。

35. D 半长轴a=(1+100000)/2=50000AU，由开普勒第三定律T=a^1.5=50000^1.5≈1.1×10⁷年，即约1000万年。
