2009年CNAO天文奥赛预赛试题

注意事项：

1. 答题前请将自己的姓名、年级、班级填写清楚。

2. 本试卷共35道单项选择题，每题只有一个正确答案。

3. 请将正确答案的字母代号用2B铅笔填涂在答题卡上。

4. 在试卷上作答无效。

5. 考试时间为120分钟，满分150分。

姓名：________ 年级：________ 班级：________ 得分：________

一、选择题（共35题，每题4分，共140分）

1. “神舟-7”飞船执行出舱任务的宇航员是（　　）。

(A)景海鹏 (B)刘伯明 (C)聂海胜 (D)翟志刚

2. 今年是望远镜用于天文观测的（　　）周年。

(A)60 (B)245 (C)400 (D)800

3. 国际通用的星座总共有（　　）个。

(A)12 (B)35 (C)88 (D)106

4. 2008年8月日全食食甚的时间大致是（　　）。

(A)上午7点 (B)中午12点 (C)下午7点 (D)午夜0点

5. 2009年全国中学生天文奥林匹克竞赛决赛的举办城市是（　　）。

(A)北京 (B)天津 (C)厦门 (D)广州

6. 2009年全国天文奥赛预赛里出现下面哪种情况被扣的分最多？（　　）

(A)未涂或涂错准考证号 (B)未涂或涂错试卷类型 (C)未涂或涂错科目（分科） (D)在答题卡上涂错某一道题的答案

7. 2008年中国队在两项国际天文奥赛中获得的金牌数为（　　）。

(A)1 (B)3 (C)5 (D)7

8. 中国即将发射的载人空间站的名称是：

(A)神舟 (B)嫦娥 (C)夸父 (D)天宫

9. 2009国际天文年的宣传口号是（　　）。

(A)保护夜空 (B)以天会友 (C)从地球到宇宙 (D)探索我们的宇宙

10. 2009国际天文年活动的全球项目“天文学100小时”举办的时间是（　　）。

(A)4月上旬 (B)7月中旬 (C)8月下旬 (D)10月下旬

11. 假设天气晴朗，2009年的以下日期中最适于进行梅西叶天体马拉松观测的日期是（　　）。

(A)2月7日 (B)3月28日 (C)4月5日 (D)5月17日

12. 银道在以下哪两个星座之间穿过？（　　）

(A)双鱼和宝瓶 (B)狮子和小狮 (C)大熊和小熊 (D)大犬和小犬

13. 从地球上看，以下哪两个天体在天球上的角距离最远？（　　）

(A)开阳和摇光 (B)南河三和北河三 (C)牛郎星和织女星 (D)心宿二和参宿四

14. 以下恒星与所在星座写的不对的是（　　）。

(A)天狼星，大犬座 (B)南河三，双子座 (C)参宿七，猎户座 (D)轩辕十四，狮子座

15. 夜空中以下哪个天体看上去最暗？（　　）

(A)土星 (B)北极星 (C)大角星 (D)牛郎星

16. 在地球赤道地区的观测者肉眼看不到的天体是（　　）。

(A)仙女座大星系 (B)大麦哲伦星云 (C)小麦哲伦星云 (D)室女座星系团

17. 以下年份中哪年可以在中国看到日全食？（　　）

(A)2012 (B)2019 (C)2022 (D)2035

18. 今年日全食食甚的时间大概是北京时间（　　）。

(A)早上6点半 (B)上午9点半 (C)中午12点半 (D)下午5点半

19. 今年日全食的全食区域从进入我国西部到离开上海附近总共持续的时间约为（　　）分钟。

(A)6 (B)30 (C)60 (D)超过90

20. 鹿林彗星现在所在的星座是（　　）。

(A)英仙座 (B)狮子座 (C)鹿豹座 (D)小熊座

21. 以下哪个不是近期的天文发现？（　　）

(A)发现到目前为止最小的类地行星 (B)荷兰三名大学生发现一颗太阳系外行星 (C)中日天文学家合作发现一颗太阳系外行星 (D)发现太阳系外行星存在生命的初步证据

22. 以下不是本月天文事件的是（　　）。

(A)土星冲日 (B)月掩木星 (C)美俄卫星相撞 (D)鹿林彗星过近地点

23. 在木星的4颗伽利略卫星中直径最大的是（　　）。

(A)木卫一 (B)木卫二 (C)木卫三 (D)木卫四

24. 到目前为止国际上已经发现的获得永久编号的小行星大约为（　　）颗。

(A)接近5万 (B)10万 (C)20万 (D)超过30万

25. 最近几天在天球上相距最近的两颗行星是（　　）。

(A)金星和火星 (B)火星和木星 (C)木星和土星 (D)土星和金星

26. 2009年相对来说观测条件不太好的流星雨是（　　）流星雨。

(A)英仙座 (B)猎户座 (C)狮子座 (D)双子座

27. 最近两年里没有发射月球探测器的国家是（　　）。

(A)日本 (B)中国 (C)印度 (D)美国

28. 一光年大约是（　　）天文单位。

(A)小于10 (B)3百 (C)6万 (D)大于1百万

29. 在北京可以看到的月球的地平高度最高约为（　　）度。

(A)32 (B)55 (C)78 (D)90

30. 某望远镜口径为120毫米，物镜焦距为1500毫米，目镜焦距60毫米，则它的放大倍数为（　　）倍。

(A)2 (B)12.5 (C)25 (D)750

31. 2009年2月9日晚上，在嫦娥一号飞船上有可能看到（　　）。

(A)日偏食 (B)日环食 (C)日全食 (D)半影地食

32. 以下哪个不是近期的天文发现？（　　）

(A)发现一颗火星共轨小行星 (B)首次观测到一颗恒星绕银心走完一圈 (C)首次在γ爆所处星系发现气体分子 (D)山东大学威海天文台发现的一颗小行星获得国际永久编号和命名权

33. 2009年在我国发生日全食时月亮位于（　　）附近。

(A)摩羯座 (B)白羊座 (C)巨蟹座 (D)天秤座

34. 以下哪句话最能够反映真实的情况？（　　）

(A)2009年元宵节的月亮是1957年以来满月里面最大的 (B)2009年元宵节的月亮是1957年以来元宵节的月亮里面最大的 (C)2009年元宵节的月亮在过去10年的元宵节的月亮里面也不是最大的 (D)2009年元宵节的月亮是近一两年的满月里面最大的

35. 冬至日在澳大利亚某地（南纬32.0度，东经141.5度）看日出，太阳应该是从（　　）方向升起来。

(A)东南 (B)东北 (C)西南 (D)西北

逐题答案与解析

1. D 神舟七号出舱宇航员为翟志刚。

2. C 1609年伽利略首次将望远镜用于天文观测，到2009年正好400周年。

3. C 国际天文学联合会1928年划定88个星座。

4. C 2008年8月1日日全食食甚时间大致在下午7点左右。

5. D 2009年第八届全国中学生天文奥赛决赛（暨广州天文奥林匹克邀请赛）于4月2—6日在广州广东实验中学举行，本届预赛在2月28日进行。

6. A 未涂或涂错准考证号后果最严重，无法识别考生身份。

7. B 2008年中国队在两项国际天文奥赛中共获3枚金牌。

8. D 中国即将发射的载人空间站名为“天宫”。

9. D 2009国际天文年口号为“探索我们的宇宙”。

10. A “天文学100小时”全球项目举办于4月上旬。

11. B 3月28日前后观测条件最适合梅西叶天体马拉松。

12. D 银道穿过大犬座和小犬座之间。

13. D 心宿二（天蝎座α）和参宿四（猎户座α）在天球上角距离最远。

14. B 南河三属于小犬座，不属于双子座（双子座有北河二、北河三）。

15. B 北极星视星等约2.0等，是四个选项中看起来最暗的。

16. D 室女座星系团距离太远，赤道地区肉眼不可见。

17. D 2035年9月2日将发生日全食，可在中国观测到。

18. B 2009年7月22日的日全食，上海食甚在9时39分，即上午9点半左右；全食带内越往西食甚越早（成都9时12分、武汉9时24分）。B 2008年8月1日日全食食甚时间约为北京时间上午9点半。

19. D 2009年7月22日的全食带从西藏南部进入我国（约北京时间8时04分），经四川、重庆、湖北、安徽、江苏、浙江，9时39分前后离开上海附近，全程约95分钟，超过90分钟。

20. B 鹿林彗星（C/2007 N3）2009年2月下旬正由室女座经狮子座向东移动，2月23—24日从土星附近经过，当时位于狮子座。

21. D “太阳系外行星上存在生命”至今没有、当时也没有任何观测证据，这条“发现”并不存在。最小的类地行星（CoRoT-7b）、荷兰三名大学生与中日合作发现系外行星都是2009年初的真实新闻。

22. A 本届预赛于2009年2月28日举行，美俄卫星相撞（2月10日）、月掩木星（2月23日）、鹿林彗星过近地点（2月24日）都发生在当月；土星冲日在3月8日，不属于本月。

23. C 伽利略卫星中木卫三直径最大。

24. C 获得永久编号的小行星数量约20万颗。

25. B 火星和木星是最近在天球上相距最近的两颗行星。

26. A 英仙座流星雨在2009年观测条件不太理想。

27. D 美国在最近两年内没有发射月球探测器。

28. C 1光年约等于63241天文单位，约6万天文单位。

29. C 在北京（北纬40°）月球地平高度最高约为78°。

30. C 放大倍数 = 物镜焦距 / 目镜焦距 = 1500 / 60 = 25倍。

31. A 嫦娥一号在2009年2月9日可能看到日偏食。

32. A 发现一颗火星共轨小行星不是近期天文发现。

33. C 2009年7月22日日全食时月亮位于巨蟹座附近。

34. C 2009年元宵节的月亮在过去10年中也不是最大的。

35. A 冬至日南半球日出方向为东南。
