第二部分：计算与简答题（每题16分，共80分）

11、2005年6月28日，天文学家在M51中发现了一颗超新星SN 2005cs，它的爆发日期是儒略日JD2453549日。随后天文学家们检测到了它的壳层膨胀过程，观测数据列入下表中。请根据表中的数据估算M51的距离。表中第一列表示观测时间（儒略日），第二列表示壳层的膨胀速率（括号里的数值是误差），第三列表示超新星的角直径。

12、假设观测者位于某球状星团的中心，球状星团内恒星的空间分布是完全均匀的（可以认为各处恒星密度相同），且恒星光度都一样。请问若观测者的极限星等提高一等，即原来能看到m等的恒星，现在能看到m+1等的恒星，请估算现在看到恒星数目是原来的多少倍？（给出比值即可，不必考虑星际消光）

13、列出你所知道的有关室女座的尽可能多的信息。比如：在天球中的位置，有关的神话传说，在某个特定日期升起和落下的大致时间，该星座里著名的亮星和特殊天体，尽可能多的相临的星座名，等等。

14、未来的某一天，人们发现了两个地外行星系统，其中的行星和地球类似。而恒星的质量分别为2倍太阳质量和0.5倍太阳质量。 （1）、以地球上的生命演化历史为参照，你认为这两个地外行星系统中，哪一个更有可能演化出像人类这样的智慧生命？为什么？（需要列出必要的公式，用数值说明原因。） （2）、如果地球人要移民到这两个地外行星上，问这两个系统中行星和恒星之间的距离大约为多少时，行星的温度才最适合我们生存？可用到的关系式：恒星的光度和质量之间的关系为：L正比于M的3.5次方。

15、假设地球与火星的公转轨道都是正圆，当地球距离火星最近时， （a）在地球上观测火星，火星在24小时中相对于恒星背景的移动角度为多少，方向应该是什么？ （b）如果在这个时候从火星上观测并发现了地球凌日的现象，问地球凌日的最长时间不会超过多少（以小时为单位）？

一、选择题答案速查

B B B C B C C C B A

二、逐题答案与解析

第01题 答案：B 狮子座与小狮座相邻——小狮座正是从狮子座、大熊座之间划出的小星座。大熊座与小熊座之间隔着天龙座，大犬座与小犬座之间隔着麒麟座，南冕座与北冕座分处天球两端，都不是相邻星座。

第02题 答案：B 天狼星赤纬约-16.7°，在北京（北纬40°）上中天时也只有约33°，位置在正南。它从东南方升起、向西南方落下，在中国任何地方都不会出现在西北方，所以“射天狼”应改为“东南望”。

第03题 答案：B 在土星参考系中，引力弹弓只改变速度方向、不改变相对速率，探测器以10km/s进来、仍以10km/s反方向离开；回到太阳参考系，这个10km/s与土星公转的10km/s同向相加，最终速度约20km/s。

第04题 答案：C 恒星颜色由表面温度决定：高温星偏蓝（O、B型），中温星偏黄白（G型，如太阳），低温星偏红（M型）。与距离远近、大气色散都没有关系。

第05题 答案：B 2007年4月宣布的Gliese 581c位于天秤座，质量约5个地球质量，恰好在其恒星的宜居带内，是当时最受关注的“可能宜居”系外行星。

第06题 答案：C 火流星是较大的流星体在高空剧烈燃烧并碎裂形成的，碎裂是普遍现象。A把星座当成了单一距离的天体（天鹅座成员星从十几光年到数千光年不等）；B若指“同时”听到则不成立，火流星的雷声总要滞后数十秒到数分钟；D的火流星判据是亮度超过约-4等，不是“比金星亮”。

第07题 答案：C 决赛期间（7月）织女星几乎整夜可见，赤纬+38.8°在厦门（北纬24°）地平以上的时间约14.9小时。五车二赤纬虽高达+46°，但夏季与太阳同方向，前半夜还在地平以下；大角午夜后西落；金星是内行星，只在昏暮或黎明很短时间可见。

第08题 答案：C 中国传统四象是东方苍龙、南方朱雀、西方白虎、北方玄武；“白象”来自佛教用语，不属于四象。

第09题 答案：B 太阳方位角90°即正西、地平高度30°，月亮方位角270°即正东、地平高度60°，两者角距正好90°，此时是上弦月。月面被照亮的部分永远朝向太阳；太阳比月亮低30°且位于观测者身后，所以面向月亮看，亮的是下边。

第10题 答案：A 天鹅座Cygnus的缩写为Cyg；Leo是狮子座、Ori是猎户座，Swc不是任何星座的缩写。

三、计算与简答题解析

第11题 用壳层膨胀法测距：由光谱测得的壳层膨胀速度v（km/s）与角直径随时间的变化率dθ/dt（角秒/年）求出距离，d[pc]=v[km/s]/(4.74×dθ/dt[″/年])。把表中各组数据分别算出距离再取平均，即可得到M51的距离（结果约为8Mpc，即2500万光年量级）。注意：本文件缺少原卷所附的观测数据表，无法代入具体数值。

第12题 星团内恒星空间分布均匀，看到极限星等m的恒星对应最远距离d，看到的数目N=(4/3)πd³·n∝d³。极限星等每提高1等，距离增大10^0.2≈1.585倍，故恒星数变为原来的1.585³≈3.98倍，即约4倍。

第13题 室女座（Virgo）：黄道十二星座之一，天区横跨天赤道（赤纬约-22°~+14°），是全天第二大星座。春季夜晚位于南方天空，角宿一与狮子座、牧夫座的大角共同组成“春季大三角”。最亮星角宿一（Spica，α Vir）约1.0等；另有东次将（ε Vir，2.8等）、角宿二（ζ Vir，3.4等）。深空天体极为丰富：室女座星系团（含M49、M58、M59、M60、M84、M86、M87——人类首张黑洞照片所在的巨椭圆星系，以及M104“草帽星系”）。相邻星座：狮子座、后发座、牧夫座、巨蛇座、天秤座、长蛇座、乌鸦座、巨爵座。神话中室女座代表正义女神阿斯特赖亚（或农业女神得墨忒耳），角宿一就是她手中的麦穗。

第14题 （1）质量0.5倍太阳质量的那个系统更可能演化出智慧生命。恒星寿命 τ∝M/L∝M/M^3.5=M^(-2.5)：2M☉恒星的寿命约为2^(-2.5)×100亿年≈18亿年，而地球上从生命出现到演化出智人用了约40亿年，时间远远不够；0.5M☉恒星的寿命约为0.5^(-2.5)×100亿年≈570亿年，是太阳寿命的5倍以上，有充足时间完成演化。 （2）要让行星温度与地球相当，行星处接收的辐射通量应等于地球：L/(4πd²)=L☉/(4π·(1AU)²)，故d=√(L/L☉)AU；又L∝M^3.5，所以d=M^1.75AU。2M☉恒星：d≈2^1.75≈3.4AU；0.5M☉恒星：d≈0.5^1.75≈0.30AU。

第15题 （a）冲日时地球与火星相距1.52-1=0.52AU=7.8×10⁷km，两者公转速度之差约29.8-24.1=5.7km/s，故火星相对恒星背景的视运动角速度ω=5.7/7.8×10⁷=7.3×10⁻⁸rad/s，24小时累计约0.36°，方向为自东向西（即逆行）。 （b）从火星上看，太阳的视直径约0.53°/1.52≈0.35°，地球的视直径约12742/7.8×10⁷≈1.6×10⁻⁴rad≈34″。地球横穿日面的角速度为0.36°/日，故凌日最长历时约(0.35°-0.01°)/0.36°/日≈0.95日，即不会超过约1天（约23小时）。
