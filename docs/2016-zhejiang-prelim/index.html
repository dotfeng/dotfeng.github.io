济南 2016年浙江省中学生天文奥林匹克竞赛预赛试题

【注意事项】请务必仔细阅读：

1.每位考生会拿到一张预赛试卷和一张答卷。试卷和答卷都需要逐题填写，并且填写的内容必须完全一致。试卷和答卷填写内容不一致的题目每题得-4分。

2.低年组考生只答本卷的01-30题，高年组考生只答06-35题。

3.本卷为闭卷考试，请答卷人按照自己的真实水平独立完成答卷，并认真、完整地用签字笔在答卷上填写有关信息、选择试卷类型（见本注意事项之前的第二项：组别），并在相应题号下书写每道题的答案。未按要求填涂的取消考试成绩。考试开始30分钟之后才可交卷，并在不影响其他考试答题的情况下安静离开考场，否则取消考试成绩。在监考老师宣布考试结束时，该考场所有考生应停止答卷，将试卷和答卷放在桌上，保持安静离开考场。

4.每题选择一个最接近正确的答案。将对应的字母（A,B,C,D之一）填在试卷上并填涂在答卷该题号下方的对应出。不会做的题目不选。已填涂的答案如需改正，请用橡皮将原答案尽量擦除干净。每道题答对得4分，答错或多选得-4分，不选得0分。满分120分。草稿可写在试卷"草稿区"处。

逐题答案与解析：

1. B “北斗七星”属于大熊座。

2. C 威廉·赫歇尔于1781年发现天王星。

3. A 太阳绕地球公转的轨道平面与天球相交的大圆称为黄道。

4. C 2016年9月17日，木星正趋近9月26日的合日，与太阳几乎同升同落，被太阳光辉淹没，在杭州不可见；此时火星、土星位于日落后西南方低空，金星为昏星，均可见。故选C。

5. A 英仙座流星雨发生在8月中旬左右。

6. C 2016年6月25日在海南文昌发射的是长征七号（首飞）；长征五号首飞是同年11月3日，长征二号丙、长征九号均不符。故选C。

7. A 当天凌晨的天象是半影月食。

8. D FAST射电望远镜口径为500米。

9. B 朱诺探测器到达木星。

10. O 第10题原卷缺失（题干与选项均无），无法作答，计分时应将该题剔除。

11. C 詹姆斯·韦伯空间望远镜将替代哈勃。

12. B 世界首颗量子科学实验卫星名为墨子号。

13. B 2016年水星凌日发生在5月9日。

14. C 双鱼座与南鱼座不相邻。

15. A 织女星与天津四角距离最近。

16. B M81位于大熊座，不是小熊座。

17. D 参宿四不属于冬季六边形。

18. D 大部分彗星有两种彗尾（尘埃尾和离子尾），D说法错误。

19. D “荧惑守心”中的“守”指的是行星的留。

20. C 木卫三是伽利略卫星中体积最大的。

21. B 哈雷彗星周期约76年。

22. C 秒差距是最大的单位（1秒差距≈3.26光年）。

23. A 太阳盘面是光球层。

24. D 角宿一（A型星）表面温度最高。

25. D 北落师门是南鱼座α。

26. B 商宿在天蝎座。

27. B 马头星云是低温尘埃和气体对背景光的吸收。

28. C 放大率=物镜焦距/目镜焦距，C选项放大率最大（2032/25≈81.3倍）。

29. C 拍银河要兼顾进光量与星点不拖尾：按曝光量 ISO×t/f² 估算，A 为 400×30/2.8²≈1531、B 为 6400×1/1.4²≈3265、C 为 3200×5/2.8²≈2041、D 为 1600×10/4²=1000。B 的总曝光量虽大，但 1 秒曝光难以积累银河暗弱结构的信号且高 ISO 噪点严重；C 在兼顾曝光时间与光圈、ISO 之间最平衡，实际能得到细节最丰富、观感最亮的银河。故选C。

30. A 太阳最终会演变为白矮星。

31. C C 项“初升的月亮看起来更大”是典型的“月亮错觉”，属心理（视觉）效应，与大气无关；A 是高阶视宁度（大气湍流）、B 是大气消光、D 是大气色差（大气棱镜色散），三者都由大气造成。故选C。

32. C 50mm口径望远镜可见最暗约10等星。

33. C 黄道光与太阳风无直接关系。

34. B 飞船轨道半径 r=2000 km，月球半径 R=1737 km。地球方向可视为固定，飞船被月球遮挡的条件是它到地月连线的距离小于 R，即 r·sinθ<R，sinθ=1737/2000≈0.869，θ≈60.3°，遮挡总张角 2θ≈120.6°。占周期比例 120.6/360≈33.5%，中断时间≈2.2 h×0.335≈0.74 h≈44 分钟，与 45 分钟最接近，故选B。

35. B 两个黑洞并合为约62倍太阳质量的黑洞。
